## 首次失败与修复

- 实际数据库中的新 Agent 实例停留在 `connecting`，没有租约。发送授权却要求实例 `online` 且租约有效。修复后，已经通过设备签名认证的发送请求续期该设备的确切实例，再检查所有权、实例撤销和 Matrix 房间权限；不能复活撤销实例或借用其他设备。
- Bridge 原来始终报告未扫描，控制平面也没有扫描自动回复正文。修复后将有界 UTF-8 正文交给服务端现有 ClamAV 服务，客户端自行声明 `riskScan=passed` 不再有效。拒绝和扫描服务不可用都会阻止发送。ClamAV 是内容恶意软件扫描，不代表模型事实核查或提示注入防护。
- 客户端加密正文不发送给服务端扫描器；要求服务端扫描的授权不能通过该模式。测试核对实际正文而非消息预览，并验证密文不会进入扫描请求。
- 公开大厅的回复可被任意成员看到，不能使用“仅已知房间成员”授权。表单增加范围说明，选择公开受众时必须保留扫描。

## 送达验收标准

必须在正式房间同时核对：真实 Codex 任务自己的 Agent 身份、原问题回复关系、固定提交编号、Matrix 接受的事件，以及网页中的实际回复正文。模型生成了文本、进程退出成功或人物显示在线都不代表送达。长期接待和结束任务后的唤醒也必须另行实际验证。
