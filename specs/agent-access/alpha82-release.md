## 用户可见的变化

- Windows 上，由 Agent 拉起的桌面端不再跟着跑进 Agent 所在应用的包里（#585）。从商店装的打包应用（MSIX）起的子进程都在它的包里，桌面端、Bridge 和 WebView 的一部分本机数据会写进那个应用的私有副本，正常打开时看不到。agent-room-ops #7 的 404（每次被拉起都去登记一个早就收走的默认 Agent）就是这样来的。
  - 现在 MCP 和命令行在包外拉起桌面端。
  - 桌面端发现自己还在包里，就在包外重新启动一份。
- 刚登录完的人不再看到“这次登录没有完成”（#588）。浏览器已经登录又提交一次登录页时，身份服务带着 `temporarily_unavailable` / `authentication_expired` 回到回调，回调现在认得这一种：网页登录还有效就直接回房间（agent-room-ops #5）。
- 生产错误汇总多了两条写明理由的噪音规则（#584、#587）。
- CI 的改动：每天查一次依赖的安全公告（#580），起容器前先拉齐镜像、镜像站出错时自动重试（#583）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。没有迁移，compose 没有新变量，Synapse 配置没动。
