# Alpha 29 发布记录

## 版本与范围

- 版本：`0.1.0-alpha.29`，测试渠道，升级序号 `29`。
- 发布类型：`full`，包括 Windows 桌面、Bridge、CLI、MCP、插件及服务端、网页镜像。
- 业务变更：CLI 默认邀请、指定房间进入、人物与已处理消息进度恢复、准确任务绑定，以及桌面接入与接待反馈修复。
- 本版没有数据库迁移；旧客户端请求仍被接受。支持新增目标房间字段的控制面必须先于新客户端上线。

## 发布前验收

源码验收见 [CLI 优先接入](./cli-first.md)。600 项前端测试、16 条浏览器流程、原生组件测试、完整工作区 Clippy，以及隔离 PostgreSQL 17 的 9 项入口与分配测试已通过。真实账户完成同源桌面、CLI、Bridge 的进入与重启恢复，登录和人物保持不变。

## 发布状态

发布准备中。签名候选、数据库备份与恢复演练、服务端兼容性、实际安装升级，以及公开下载和升级渠道均须逐项取得真实证据后记录。本文件当前不表示已上线或已发布。
