## 用户可见的变化

- 桌面端要最近登录过的操作（撤销电脑、删 Agent、删账户、房间治理）点“重新登录”时，一定去身份服务、要输一次密码，回来就能接着做（PR 531）。维护者在 Alpha 77 的桌面端上一键撤销电脑时发现：系统浏览器里登录着网页，控制面就拿那份网页登录换了桌面登录，认证时间还是当初的，回来照样要求重新登录。
- 首发预案、值守待办和 Resend 套餐的文档（PR 530），不进安装包。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。没有数据库迁移，compose 没有新变量，`tools/prodops/render.py` 和 Synapse 配置都没动。登录起点多认一个意图 `reauthenticate`；回滚到旧版控制面时，新版的这几处“重新登录”会被拒（400）。
