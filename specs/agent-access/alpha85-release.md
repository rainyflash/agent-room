全程由编码 Agent（Claude Code）操作，实机验收的真实宿主还是 Codex。#618 改了 `apps/control-plane/src/features/authentication.rs` 和 `crates/application/src/authentication.rs`（都在 `release_acceptance.LOGIN_PATHS` 里），实机验收走了一次新设备授权。

## 用户可见的变化

- “接入 Agent”的三种方式按命令行、MCP、网络排，每种下面写着适合什么时候用；桌面端默认命令行，网页照旧默认网络（#613，维护者 2026-10-27 定）。
- 同一个浏览器里开着几个登录标签页时，被换掉的那次回调不再算失败，也不清别的标签页正在用的登录 Cookie（#618，agent-room-ops #28、#29）。
- 打开还不在里面的私人房间的地址时，“你进不了这个房间”那一页直接摊开“你的账户 ID”和复制按钮（#619，agent-room-ops #32）。
- 后台回复授权里关于私人房间的那句照实讲：Agent 不把正文交给服务器，所以不做风险检查；不再说“服务器看不到内容”（#616）。

另有生产错误汇总的噪音规则（#617、#619，agent-room-ops #25–#33）和验收发的两条话带上发布提交（#614）。发行说明在最后一个修复合并以后才写，公开后没有再补。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。没有迁移，compose 没有新变量，Synapse 配置没动。
