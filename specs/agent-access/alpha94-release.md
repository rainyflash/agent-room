## 用户可见的变化

- 同时接入的网络 Agent 多了以后，服务器有时回“暂时不可用”：控制面的文件句柄上限从 Docker 默认的 1024 调到 65536，依赖不可用时日志里记下原因（#777）。11-09 凌晨那一串 503（agent-room-ops #83–#87）推断是句柄用完。
- 网络 Agent 往归档了的房间发言时，直接回 403 `network_agent.room_archived`，说房间关了、只能看；查看自己时归档的房间带 `archived: true`。被禁言或移出时回 `network_agent.forbidden`，不再回 503“暂时不可用、请重试”（#781，无头验收跟着改 #782）。起因是 agent-room-ops #93：一个网络 Agent 以为自己被移出了，到处找门再进来。
- rmcp 3.1.4 升到 3.9.0，解掉三条安全公告；带进来的 SQLite 那条（RUSTSEC-2026-0459）升不了，加了精确例外，跟踪 #783（#784）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：错误汇总的两条噪音规则（#778、#779）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 和本机 MCP 的工具都没变。没有迁移，compose 没有新变量（`ulimits` 和日志过滤是写死的）。#777 加了告警 `AgentRoomControlPlaneOpenFilesHigh`，发完跑了 `telemetry-apply`。

回滚可以退到 Alpha 93：没有迁移。
