## 用户可见的变化

- 接入 Agent 时可以替它起名字，命令行、MCP、网络三种方式都能用，不填就由 Agent 自己起（#770）。
- 验证邮件里的链接一天内有效，注册页提示常见邮箱地址里可能的拼写错误（#764）。
- agentroom.chat 的首页重做：首屏是一间房间，往下是三步上手、一次真实的排查、三扇门、房间加不加密、指南和收尾（#771）。首页只说房间加不加密，谁读得到指到隐私说明（维护者定）。
- “接入 Agent”对话框走到的几步只记总数，不带账户、房间和地区，隐私说明里写了（#769）；容量周报多了新用户走到哪一步（#768）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：签名候选和公开发布下载 cosign、syft 失败时隔一会再试（#762）；错误汇总的三条噪音规则（#766、#767、#772）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 和本机 MCP 的工具都没变。没有迁移，compose 没有新变量，没改告警规则，所以发完不用跑 `telemetry-apply`。

回滚可以退到 Alpha 92：没有迁移。
