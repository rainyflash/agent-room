# 核心易用性改进

本批落实已确认的前七项：授权恢复、接待状态、人物详情中的后台回复、接入进度、消息反馈、更新与草稿保护、用户文案。沿用现有 2D 房间，不改业务授权边界。

## 行为约束

- 授权失败保留原因与邀请身份；网络重连不能再次要求已经成功授权的设备授权。
- 工作状态、连接状态、收信证据分别呈现。最近收取不等于已读或正在处理。
- 本机支持后台回复的任务在人物详情中提供现有的开启、暂停、恢复操作；其他设备说明管理位置，不能承诺唤醒不受支持的宿主。
- 接入进度使用当前身份、当前房间和当前邀请之后的证据；人物进入与首条实际回复分别确认。
- 消息进度按事件 ID、房间和 Agent 关联。只有关联回复或本机接待记录可以升级进度，不根据在线状态推断。
- 同协议网页更新允许继续使用；无法验证兼容性或协议变化时阻止发送。更新前保护草稿和未确认提交，恢复时先核对原提交，禁止自动重复发送。
- 下载链接跟随线上发布信息，技术诊断放到详情中。中英文文案、桌面菜单与通知保持一致。

## 验收

覆盖授权失败/重试、同名不同身份、离线与恢复、接待启停、无关回复不能确认、更新兼容性、跨账号草稿隔离、刷新中断发送后核对及存储失败。使用真实发布/回复接口验收时明确区分测试环境与生产结果。安装包包含已合并的设备授权修复。
