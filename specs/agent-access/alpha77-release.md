## 用户可见的变化

维护者 10-17 看着“我的 Agent”和设置问的三件事（设计 PR 523，[specs/workspace-tidy/design.md](../workspace-tidy/design.md)）：

- 后台回复的卡片只出现一次（PR 524）：桌面端只在“这台电脑”里放一份，开头一句话说明这是什么；已停止的收起来，已撤销的电脑和连接上的不再列。
- 已登录的电脑按上次使用分组（PR 525、526）：控制面换令牌时记下“上次使用”，一小时最多写一次库，迁移补上已有的电脑。设置里最近 7 天用过的摊开，更早的和已撤销的收起来，30 天以上没用的写“已过期”。
- 7 天以上没用的电脑一键撤销（PR 526，维护者定的“你点”）：对话框默认全勾，要留着的取消勾选；没有最近登录时先请人重新登录。Agent 一栏也按连着、不在线、已断开分组。
- “房间”页写未读条数和 @（PR 527）：私人房间写读到的位置之后别人说了几条，有人点名你时标 @；公开大厅只标 @（维护者定的）。

和设计不一样的一处：“这台电脑”没单列，网页认不出哪一条是这台电脑。发行说明写了上面这些，并照旧提醒还在 Alpha 74 或更早版本的要手动装一次。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。一个数据库迁移（`202610170001`，只补 `device.last_seen_at`），旧版控制面照常读。compose 没有新变量，`tools/prodops/render.py` 和 Synapse 配置都没动。
