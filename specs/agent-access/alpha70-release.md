# Alpha 70 发布记录

[Alpha 70](https://github.com/rainyflash/agent-room/releases/tag/v0.1.0-alpha.70) 于 `2026-10-11T12:46:09Z` 公开。

- 升级序号 `70`，源码 `9455f82b919c86255475aef68ea67b5c7cf33954`（[PR 406](https://github.com/rainyflash/agent-room/pull/406) 的合并提交）。
- 网页、服务器和维护者本机的 Windows 应用都已升级。
- 本版在受保护的 `release/v0.1.0-alpha.70` 分支上以锁定模式公开，是正式版，标为 Latest。

全程由编码 Agent（Claude Code）操作，实机验收的真实宿主和上一版一样用 Codex。版本 PR 合并以后整条链由后台脚本接着跑，一次也没停。

## 用户可见的变化

### 网页顶栏的 GitHub 和下载应用

维护者说网页上登录以后找不到下载按钮，Mac 版下不了新版本，顶栏还要有 GitHub 链接（[PR 405](https://github.com/rainyflash/agent-room/pull/405)）。

- 网页顶栏右边加了 GitHub（只放标志）和“下载应用”：按访客的系统直接给安装包，提示里写是哪个系统的。地址和首页一样从运行时清单读，跟着每次发版换。手机和 Linux 上不显示下载，桌面端顶栏两样都不加。
- 右边放不下时按宽度收：1260px 以下“退出登录”只留图标，1140px 以下下载也只留图标，761–1000px 名字收起来只留标志。顺带修好桌面端顶栏在 800px 左右名字压住“房间”、“退出登录”折成两行。

### 定时备份不再占几分钟 CPU

[PR 403](https://github.com/rainyflash/agent-room/pull/403)：读清单只看路径字面，不再碰文件系统；发布了的快照按清单记着的字节数算大小，不再逐个 `lstat` 整个仓库。见下面“上线后的定时备份”。

发行说明写了顶栏的两样、备份不再占 CPU，以及装着 Alpha 68 或更新版本的桌面端开着就会提醒这一版。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 仍是 `4.4`。这一版没有数据库迁移。
