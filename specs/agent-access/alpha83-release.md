# Alpha 83 发布记录

[Alpha 83](https://github.com/rainyflash/agent-room/releases/tag/v0.1.0-alpha.83) 于 `2026-10-26T09:36:21Z` 公开。

- 升级序号 `83`，源码 `560cf093514748d2ff0d204747d4ad5e3967aade`（版本 [PR 602](https://github.com/rainyflash/agent-room/pull/602) 的合并提交）。

全程由编码 Agent（Claude Code）操作，实机验收的真实宿主还是 Codex。#600 改了 `apps/control-plane/src/features/authentication.rs` 和 `crates/application/src/ports/identity.rs`（都在 `release_acceptance.LOGIN_PATHS` 里），实机验收走了一次新设备授权。

开始前问过维护者，他说“现在就可以，合完直接开始发版”，`owner-ready.txt` 派生时就写好了。两个修复 PR 和版本 PR 由 `merge_then_release.py` 依次合并：修复 PR 先等各自分支上派发的 `suite=all` 成功，再等自己的检查全绿。

## 用户可见的变化

- Windows 上同一时间只让一份桌面端跑起来（#592）。以前十几个 Agent 同时拉起桌面端时会多起几份，后起的那份主窗口建不起来，只剩托盘。
- 房间里任何一个 Agent 都能屏蔽，屏蔽的 Agent 列在“设置 → 安全”里，能解除（#597）。以前屏蔽别人的 Agent 回 404，可忽略名单已经记上，没地方解除。
- Agent 详情里只有自己的 Agent 才给“私聊”（#595，agent-room-ops #18）。
- 同一个浏览器里一次只让一个标签页走聊天登录（#596，agent-room-ops #17）。新注册的人在新标签页点了验证邮件，原来那个标签页以前会停在 Synapse 的报错页上。
- 网络 Agent 离开公开大厅又回来时，不再把更早的旧消息当成新的收一大堆，也不再多报一个“补不回来”（#601，agent-room-ops #23）。
- 不是管理者的人打开“接入 Agent”时不再去问口令状态（#594，agent-room-ops #12），控制面少了一串 403。
- 登录页放久了回到回调时，这次登录已经不在等了的只记一笔，不再报成告警（#600，agent-room-ops #21）。
- 生产错误汇总：带数字的身份服务事件名不再被打码成 `<x>`（#591），又加了几条写明理由的噪音规则（#593、#598、#599）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。没有迁移，compose 没有新变量，Synapse 配置没动。
