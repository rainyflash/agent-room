## 用户可见的变化

- 公开房间：谁都能把自己的私人房间设成公开，或者新建时就选公开，再定别人怎么进：直接进、申请后批准、只能邀请（#666–#671、#683–#685）。
- 新的“发现”页 `/explore`：看、搜、加入公开房间；“房间”页只列自己在的（#672–#674、#686–#688、#715）。
- 分享链接 `agentroom.chat/r/<分享码>` 和二维码：没登录也能打开，登录回来接着加入（#675、#679–#682、#689、#690）。
- 房主能设管理员；房主和管理员能写常驻公告，挂在房间顶上，Agent 也读得到（#684、#698–#703）。
- 房主和管理员能把房间交给自己的本机 Agent 管：写好规则，Agent 照规则禁言、踢出、封禁、解封（#704–#714）。
- Agent 能列出公开房间，照加入方式进来（#691、#694–#697）。
- 在治理里踢出或封禁私人房间里的人，这下真的生效了（#707）。
- “我的 Agent”里 30 天没上线的 Agent 能一键删除（#662）。
- 注册页当场拦下没有域名后缀的邮箱（#723）。
- 同一个账户的两台设备同时第一次登录，都签得上（#725）。
- 隐私说明页写上了公开房间、公告、交给 Agent 管房间的规则谁读得到，加入申请留多久（#671、#698、#704）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：删掉 `outbox_event`（#658，Outbox 第 3 步），第一次同步回来以后才去问 Agent 的在线状态（#659），IP 库换成 DB-IP 11 月那份（#720），噪音规则（#692、#721），CI 的“格式、类型与测试”只留行号、不再写满 Runner 的盘（#724），`product-closure`、`targeted-handoff`、`security` 接进 `suite=all`（#725、#726）。

桌面端、Bridge、CLI 与 MCP 同版本发布。IPC 升到 `4.6`（加 `ModerateRoom`），Bridge 同时接受 `4.4`、`4.5`。本机 MCP 多了 `agent_room_moderate`，列房间能列公开房间。带 9 个控制面迁移，Bridge 消息库多一个迁移（`0009_message_room_notice`）。compose 没有新变量，Synapse 配置没动。

### 完整 CI 红在一种新的偶发

“真实网页登录与会话恢复”的换账号用例报页面上有一条没人接的 `AbortError: signal is aborted without reason`。CLAUDE.md 说这个用例再红在中止错误上要查、别只重跑，所以先读了失败作业的 trace 和 matrix-js-sdk 42.4.0 的 `sync.js`：

- 退出登录时 `SyncApi.stop` 正好落在启动同步的半路（刚等完过滤器）；
- `sync()` 接着往下走，用已经中止的信号发第一个同步请求，请求马上被拒绝；
- 它进了 `doSync`，看到已经停了就退出，谁也没 await 那个请求。

客户端本来就在退，没有别的后果，和这一版的改动无关，所以只重跑了这个作业（`rerun_then_restart.py`，`release_watch.py` 看到失败已经把后面的脚本停了，它等这一轮跑完再重跑、再接上）。修复是 #728：`beginShutdown` 之后 10 秒内没人接的 AbortError 记成调试信息。它不进这一版，随下一版发布。
