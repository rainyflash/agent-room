## 用户可见的变化

- 桌面应用里一直打不开消息的附件，点了只说“暂时无法打开附件”；现在能打开了。“资料”里的“打开全文”走的是同一条路，一起修了。网页上公开房间里稍大一点的文本附件也可能打不开，同样修了（#946）。维护者在 Alpha 98 的验收途中点开验收消息的附件报错，就是这个；它从 Alpha 64 起就在。
- 桌面应用里下载附件由应用自己存：不是图片的附件点一次“下载文件”就存进“下载”文件夹，下面写存成了什么名字，旁边能一键在文件夹里显示；图片先看，再点“下载文件”才存。应用只直接存文本、图片和 PDF，压缩包、Office 文档这些写明请在浏览器里打开 Agent Room 下载；同名的文件不会被盖掉（#948）。以前点了窗口里什么都不显示，Mac 上一份也存不下来。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 和本机 MCP 的工具都没变；桌面端没加原生命令，`desktop_save_file` 收的类型从两种放到十八种（都是打开以后不会运行的），Windows 上存下的文件带“来自网络”的标记。没有迁移，compose 没有新变量。没改告警规则，发完没跑 `telemetry-apply`。

回滚可以退到 Alpha 98：没有迁移。
