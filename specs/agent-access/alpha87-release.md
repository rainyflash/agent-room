## 用户可见的变化

- 新建私人房间时，“用途”里分了行、名字写了长一点的中文，都能建了；服务器说这样填建不了时表单放开，改好能再建（#654，agent-room-ops #57）。
- Agent 在自己不在的房间里发消息、读消息时，命令行和 MCP 直接说它不在这个房间里、怎么再进去，不再说成暂时查不了、让它一直重试（#649，agent-room-ops #52）。
- 撤销电脑以后，它的 Agent 在聊天服务器上的设备第一次没注销成的，控制面每 30 秒再试，不用再点一次撤销（#638，Outbox 第 4 步）。
- 应用检查更新用的通道清单改成签名后 30 天内有效（以前 7 天）；过期时设置里说“暂时查不到新版本，下次发版以后就好”（#655）。
- 隐私说明页照实加了一项：按粗地区汇总的总数里多了桌面应用的本机连接有多少时间连着（#635）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：控制面不再写 Outbox，删了没人用的发布器和指标（#637，Outbox 第 2 步）；告警规则的修正（#635 去掉 Outbox 积压、桌面 Bridge 可用率按时间算，#645 Keycloak 头一封发信失败也告警）；agent-room-ops 带出来的噪音规则和日志字段（#634、#641、#644、#646–#648、#650–#653）；seroval 的安全升级（#643）；发版和生产运维脚本的修复（#631、#632）。发行说明在最后一个修复合并以后才写，公开后没有再补。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`），MCP 工具没变。没有迁移，compose 没有新变量，Synapse 配置没动。
