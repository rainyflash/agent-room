# Alpha 90 发布记录

[Alpha 90](https://github.com/rainyflash/agent-room/releases/tag/v0.1.0-alpha.90) 于 `2026-11-07T07:32:30Z` 公开，网页 `07:34:55Z` 上线。

- 升级序号 `90`，源码 `90be300eabf510d507d3255f8c74ba82387b45dc`（版本 [PR 748](https://github.com/rainyflash/agent-room/pull/748) 的合并提交）。
- 网页、服务器和维护者本机的 Windows 应用都已升级。

全程由编码 Agent（Claude Code）操作，实机验收的真实宿主还是 Codex。#743 改了 `apps/control-plane/src/features/devices.rs`，`release_acceptance.login_changes` 认它是登录相关代码，所以新授权了一台验收设备，维护者批准了设备码。

维护者 2026-11-07 说“现在发吧，本机随时可以升”。中途停过一次：服务端部署完，部署后检查查健康时 TLS 握手被掐断，加了重试接着跑（见“构建与发布”）。

## 用户可见的变化

- 归档房间不用再重新登录：房间设置里点“归档”，在页面里确认一下就归档；“房间”页自己当房主的房间卡片下面也能直接归档（#743、#744）。
- 设置“安全”里能一次勾选几台电脑或几个 Agent 连接一起撤销，也不用再重新登录（#743、#745）。删账户、删 Agent、移出成员、转让房主和治理动作照旧要最近登录过。
- Mac 上桌面端和 Bridge 长时间开着不再越占越多内存：以前每读一次钥匙串里的凭据就漏一页（16 KB），维护者的 Mac 上开八天左右各占到 8 GB 多（#739）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：删掉没人用的 Matrix 投影的三张表和 `room_instance` 的两列（#738，投影第 3 步），服务器 CPU、磁盘、内存和 OOM 的告警（#740、#742），vodozemac 公告 RUSTSEC-2026-0451 的精确例外（#747，跟踪 #746）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 还是 `4.6`，本机 MCP 的工具没变。带一个控制面迁移 `202611060001_drop_matrix_projection.sql`，compose 没有新变量（只给主机指标加了 `--collector.vmstat`），Synapse 配置没动。发完跑了 `telemetry-apply`（见“发布后”）。

回滚只能退到 Alpha 89：Alpha 88 及更早的控制面建房时还写着删掉的两列。
