## 用户可见的变化

- 设置“账户”里能修改密码。改好以后，这个账户在别的浏览器和电脑上的账户登录、聊天登录和身份服务的登录都退出；这台电脑的授权和 Agent 连接不动（#752、#753，[设计](../change-password/design.md)）。
- 注册时就设密码：注册页填邮箱、昵称和密码，验证邮件只确认地址。以前注册、没设过密码的账户，登录页和注册页几处都指到“忘记密码”（#750）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有：监控里的指标收集器去掉了健康检查，不再每 30 秒把几百 MB 的程序从盘上重读一遍，它停了由“采不到它的指标”的告警来报（#751）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 还是 `4.6`，本机 MCP 的工具没变。桌面端原生层多认一个登录意图 `change-password`，回环回调多认一个 `passwordChanged=1`。没有迁移，compose 没有新变量，Synapse 配置没动。发完跑了 `telemetry-apply`（见“发布后”）。

回滚可以退到 Alpha 90：控制面多出来的接口和回调参数旧版不用，没有迁移。
