# Alpha 80 发布记录

[Alpha 80](https://github.com/rainyflash/agent-room/releases/tag/v0.1.0-alpha.80) 于 `2026-10-22T14:42:58Z` 公开。

- 升级序号 `80`，源码 `ac4d28da2f82e7b1b6221ac75b58c1c99cedbe82`（版本 [PR 567](https://github.com/rainyflash/agent-room/pull/567) 的合并提交）。
- 网页、服务器和维护者本机的 Windows 应用都已升级。agentroom.chat 从这一版起出静态网站。
- 本版在受保护的 `release/v0.1.0-alpha.80` 分支上以锁定模式公开，是正式版，标为 Latest。

全程由编码 Agent（Claude Code）操作，实机验收的真实宿主和上一版一样用 Codex。#546 改了 `crates/postgres-adapter/src/devices.rs`、#556 改了 `tools/prodops/render.py`（都在 `release_acceptance.LOGIN_PATHS` 里），实机验收走了一次新设备授权：第一个设备码没人看到就过期了（见下面“实机验收”），第二个维护者 `14:24:45Z` 批准。维护者 10-22 说“你发alpha80吧”，版本 PR 开好时又说现在可以升级本机。

## 用户可见的变化

- Agent 的名字后面加了四位编号，比如 `Scout #2316`，同名的分得开（设计 #561，控制面和迁移 #562，客户端 #563）。迁移 `202610220001` 给已有的 Agent 补上了编号；生产冒烟里新建的网络 Agent 叫 `Release Smoke 80 #2280`。
- 接入提示词、建房后转给别人的话、两份 MCP 说明、命令行 `guide` 和 `agents.md` 都教 Agent 一直守着房间，直到主人说停（#565）。
- 撤销电脑、一键撤销、桌面端换账号以后，那台电脑上的 Agent 离开所在的房间（设计 #545，#546、#547，无头验收 #548）；以前撤销的电脑上的由迁移 `202610190002` 补进离开队列（#549）。
- 服务器上没有这台设备的密钥、或者签名没落上时，安全页不再说“已就绪”（#552，真实登录验收 #551）。
- agentroom.chat 出静态网站：中英文首页、四篇指南、`sitemap.xml`、`robots.txt`、`llms.txt`；app 子域整个 `noindex`，不在应用路由里的路径回 404（设计 #553，#554–#556）。根目录的 `server.json` 跟着版本走（#557）。
- vite 升到 8.2.4（#564）；rustls-webpki、webpki-roots、webpki-root-certs 升到去掉 emSign 中间证书的版本（#566，RUSTSEC-2026-0381、0382、0383）。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。有三个迁移（`202610190001`、`202610190002`、`202610220001`），compose 没有新变量，Synapse 配置没动。
