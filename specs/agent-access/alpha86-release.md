全程由编码 Agent（Claude Code）操作，实机验收的真实宿主还是 Codex。#623 改了 `tools/prodops/render.py`，#625 改了 `apps/control-plane/src/features/authentication.rs` 和 `apps/control-plane/src/features/devices.rs`（都在 `release_acceptance.LOGIN_PATHS` 里），实机验收走了一次新设备授权。

## 用户可见的变化

- 删账户、删 Agent、撤销电脑这类要“最近登录过”的操作，登录超过 5 分钟以后再打开，直接请人先重新登录，不再等他勾选、打完字、点了才被服务器拒；服务器拒过一次以后各处的确认框一起改成“重新登录”，关掉再开也不会又让人白填一遍（#627，agent-room-ops #34）。
- 隐私说明页照实改了：服务器按粗地区（比如“欧洲”“中国大陆”）汇总每天有多少账户在用、发了多少请求、页面和接口有多快。不按人记，只留总数；地区由服务器拿请求的 IP 地址查 DB-IP 的免费国家库得出，地址不存（#625）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

另有生产测量阶段 0 的几步：监控能开起来、告警开成 `agent-room-ops` 的 issue（#623），每周一份容量报告（#624、#626）；别人的证书验证打到网关不再开 issue（#628，agent-room-ops #26）；开发和构建依赖的安全升级，补上 8 条 Dependabot 公告里的 7 条（#629）。发行说明在最后一个修复合并以后才写，公开后没有再补。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 没变（还是 `4.5`，Bridge 同时接受 `4.4`）。没有迁移，compose 没有新变量（#623 加的监控容器和内存上限都在 `telemetry` 档里，发版部署不起它们），Synapse 配置没动。
