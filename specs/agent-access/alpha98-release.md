## 用户可见的变化

- 桌面应用里点邀请卡片、分享卡片的“保存图片”，或者设置里的“下载我的数据”，以前窗口里什么都不显示：Windows 上文件其实悄悄存进了“下载”文件夹，Mac 上一份也存不下来。现在由应用自己存进“下载”文件夹，存完在按钮下面写存成了什么名字，旁边能一键在文件夹里显示；没存成也会说，同名的文件不会被盖掉（#944）。维护者在装好的 Alpha 97 上点“保存图片”说没反应，就是这个。
- 只凭网络接入的 Agent 名字带着编号还和别人撞上时，换的随机编号不会再抽回刚撞上的那一个（#942）。
- 发行说明照旧提醒还在用 Alpha 74 或更早版本的人手动下载安装一次。

桌面端、Bridge、CLI 与 MCP 同版本发布，IPC 和本机 MCP 的工具都没变；桌面端多了两条原生命令（`desktop_save_file`、`desktop_show_saved_file`）。没有迁移，compose 没有新变量。没改告警规则，发完没跑 `telemetry-apply`。

回滚可以退到 Alpha 97：没有迁移。

  - “保存图片”：按钮下面写了“已存到“下载”文件夹：agent-room-发布验收.png”，“下载”里多了这张图，1080×1350、约 155 KB。

  - “复制图片”：按钮变成“图片已复制”，剪贴板里是 1080×1350 的图。

## 本机发布脚本

- `derive_alpha98.py` 从 Alpha 97 派生，平常的写法（上一版 97、这一版 98），Alpha 97 一次性的三个脚本没带。
- 等最后一个修复合并的那段时间先把能备的备好：版本工作树、发行说明、派生脚本试跑一遍。#944 合并 4 分钟后版本 PR 就开出来了。
- 这一版新加两个脚本，留在 `artifacts/releases/alpha98`，下一版派生时会跟着带上：
  - `watch_release.py`：盯发布日志的关键行，每行只报一次（报过的记在旁边的状态文件里，重新挂上不会重报），25 分钟没有日志在长也报一次。
  - `click_save_image.py`：验收跑完以后手动跑，在装好的桌面端上点邀请卡片的三个按钮，再核对“下载”里的图和剪贴板。公开那一段不用桌面端，可以同时跑。
- 写这类脚本别用 heredoc 带反引号或反斜杠的内容：这一次给 `CLAUDE.md` 加一句话时，没加引号的 heredoc 把反引号里的字当命令执行、吞掉了，对着结果才看出来。
