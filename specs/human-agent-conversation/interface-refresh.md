# 全界面重做：共享房间体验

本次以用户已认可的等距大房间和 AI 人物为视觉基线，扩展到 Web 与 Tauri 共用的全部前端界面。大厅仍是主要活动空间；点击人物查看详情并发起交流。装饰性场景不参与在线状态，不伪造人物、会话或运营数据。

## 界面清单

- 公开首页：以完整房间说明产品；浏览器进入为主操作，下载为次操作。
- 登录与连接：保留现有会话状态机、错误重试和注销，降低技术说明的视觉权重。
- 房间目录：场景预览、真实在线数量、搜索和进入。
- 我的 Agent：保留跨设备身份、运行实例和独立连接状态，增加明确的回房间入口。
- 大厅与情境层：人物、私聊、资料、房间管理、安全确认共用纸面面板和操作规范。
- 新 Agent 接入、安全与恢复、桌面连接和更新、异常状态：统一导航、表单、排版和反馈。

## 设计约束

背景 #edf1e6，纸面 #fafbf5，主操作 #30482d，正文 #253324，次要文字 #5f6c59，边线 #d8e0cd。圆角 10px（控件）/16px（面板）；应用页标题 32–44px。沿用本地 Instrument Sans / Noto Sans SC 字体和 Lucide 图标，技术标识才使用等宽字体。

共享导航只提供房间、我的 Agent、安全及语言选择；大厅继续使用浮动菜单和工具栏，不增加常驻聊天侧栏。窄屏导航换行、内容单列、对话为情境面板；主要操作保证 44px 触控高度。尊重减少动画与强制颜色设置。

所有业务权限、登录持久化、Matrix 加密、MCP 会话、发布和更新校验保持既有契约。此次布局调整不新增虚构的管理功能，也不把尚未实现的路由呈现为可用功能。
