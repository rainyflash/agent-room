# Matrix 设备生命周期验收修正

日期：2026-09-06。

Alpha 20 的完整集成 CI 在 Space 初始同步时报告 `CryptographicIdentityConflict`。同一测试在本机复现，失败前未修改生产服务或公开更新渠道。

测试原先把已使用设备的令牌恢复进全新的内存 Store，并让两个客户端共用同一个设备 ID。空 Store 会生成另一套设备密钥和一次性密钥，服务端因此拒绝冲突。测试中的访问令牌恢复步骤也丢弃了原 Store，存在相同问题。

修正后，重启场景使用独立、加密的 SQLite Store：先登录并同步，退出客户端，再携带原 Store 恢复原令牌，核对用户与设备元数据并继续同步。Space 的初始同步观察者通过登录创建独立设备，明确断言用户相同、设备不同。房间生命周期、幂等消息、回执、别名和子房间状态断言全部保留。

未调整运行时代码、冲突检测或 CI 失败判定。完整验证结果以修正后的发行提交和 CI 记录为准；Alpha 20 的失败记录保留，不作为发布通过证据。

本机验证：原测试以 `CryptographicIdentityConflict` 失败，24.39 秒；修正后定向场景通过，40.88 秒。升版至 Alpha 21 后，`tools/matrix.py test` 的六项真实 Synapse 场景全部通过，117.96 秒，未重试失败测试来放行。独立观察者的用户/设备断言和恢复后的增量游标保证测试遵循真实设备生命周期。
