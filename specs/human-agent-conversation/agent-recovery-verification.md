# 桌面 Agent 身份与加密历史恢复

日期：2026-09-06。补齐已有加密身份在新设备上缺失本地密钥时的恢复入口，保留游戏房间与点击人物交流的主界面。

## 行为

桌面安全中心列出本机正在运行的宿主任务。用户选择 Agent 后，可以设置至少 12 个 Unicode 字符的恢复口令，或者输入该 Agent 已保存的口令/恢复密钥。没有运行中任务时显示启动指引。

原生适配器复用当前任务的 Matrix 客户端，调用官方 SDK 的秘密存储与密钥备份接口。设置时只允许建立缺失的交叉签名身份，不覆盖已发布身份或既有恢复配置。恢复时校验导入密钥，恢复原身份和当前已加入加密房间的可用备份。

恢复入口使用独立 `MatrixRecoveryManage` IPC 权限，只授予桌面壳；MCP 与诊断 CLI 均无法请求此权限。MCP 工具总数仍为 12，不增加接收恢复密钥的工具。会话摘要只包含句柄、名称和运行状态。

口令限制为最多 1024 UTF-8 字节，拒绝空白与控制字符。原生秘密类型的 Debug 输出脱敏，释放时清零。前端凭据只存于当前表单；失败、取消或切换任务时清空。一次性恢复密钥只存于当前确认视图，不进入 React Query 缓存和浏览器持久存储。人类账号的原恢复表单同步移除了密钥在 mutation 缓存中的残留。

## 已执行验证

- 真实 Synapse 上注册隔离 Agent，创建备份和加密历史；两个独立新设备分别用口令、恢复密钥恢复。检查公开主密钥始终一致；新设备恢复前不能读取旧明文，恢复后能够解密旧消息并继续发送密文。错误口令和覆盖已有备份均被拒绝。场景通过，27.11 秒。
- 使用仓库 `.venv` 执行 `tools/matrix.py` 对应的 `real_synapse` 测试入口，过滤 `新设备恢复` 并显式启用 ignored 场景；自动生成独立测试身份，不操作生产账号。
- 恢复 UI、原生传输契约与原有安全模块定向测试通过；覆盖一次性显示、缓存不保留凭据、任务切换、错误口令、空清单、闭合响应和 Unicode/字节边界。
- 安全中心三个 Playwright 场景通过，包括 390px 恢复操作、无横向溢出与确认后移除密钥。截图位于本机忽略提交的 `artifacts/browser/agent-recovery-mobile.png`。

这份记录证明恢复契约与本地可操作性。签名候选、生产部署和旧版安装升级以本次发行证据为准。
