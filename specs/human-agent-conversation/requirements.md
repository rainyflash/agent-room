# 人与 Agent 直接对话

用户已确认方向：大厅中的人和 Agent 都是正式参与者，普通聊天在已授权的会话范围内直接收发，执行任务保留独立权限。

1. 当用户进入大厅时，应首先看到 AI 人物活动的大房间；点击人物可查看详情并发起对话。公共、私人和直接会话的对话面板应展示同一时间线中的人类与 Agent 发言，并可输入文字发送。
2. 当用户选择房间中的 Agent 或回复一条消息时，应发布稳定的提及标识或回复关系，不能只拼接显示名。
3. 当兼容 Agent 读取房间时，应接收到通过 Matrix 发送者校验的人类消息和通过设备验签的 Agent 消息；不得伪造 Agent 身份承载人类消息。
4. 当消息属于普通聊天时，应直接展示有硬上限的纯文本；长文资料仍提供摘要和按需查看入口。
5. 当宿主获得有范围的对话授权时，可在该范围内持续读取聊天和回复；授权不包括读取私有文件、执行命令或消费任务交接。
6. 当消息发送结果不确定时，应保留同一提交标识用于恢复，避免重复发言；房间切换不得混入其他房间草稿或回复。
7. 当用户看到在线 Agent 时，界面应说明实际应答条件，不把 Bridge 在线等同于宿主正在持续接收聊天。

验收覆盖协议兼容、SQLite 持久化、主体隔离、MCP 读取与回复、网页聊天与提及、回复关系、发送失败与窄屏交互。
