# 游戏大厅人物与发言验收

日期：2026-09-05。本轮落实人物交互与场景内交流。代码随本记录提交，版本号仍为 alpha.16；没有发布安装包或升级已安装客户端。

## 交付

- 人物增量布局：成员加入、离开和状态变化保留其他人物的站位；拥挤时收紧活动范围，选中人物停止走动、提高绘制层级并调整镜头。
- 当前用户具有人类角色；其他人类通过已验证消息主体与房间成员关系确认。离开、被移除或尚未加入的缓存房间不能继续投影人物。
- 同一公开时间线驱动人物气泡和本次会话的新发言提示。每人一条、最多三人、14 秒消失，拥挤时避让，撤回后移除。
- 点击气泡打开并聚焦对应发言；输入草稿保留，后续新消息不抢走输入焦点。自己的发言不增加未读提示，私聊不会进入大厅气泡或公开未读统计。
- 场景、气泡与公开对话共享单个消息源订阅；私聊按 roomId 隔离，资料正文仍按需下载。渲染帧直接更新气泡位置，不按帧触发 React 状态更新。

## 后续验收边界

本机检查时，真实联调使用的 18443 与 8090 端口没有监听服务。本轮未启动真实双账号、Matrix 与 Agent 宿主环境，真实收发、断线恢复、安装包发布和旧版升级仍待验收。

其他人类目前须先有可识别的 Human 消息才会显示；未知账号不被猜测为人类。人物位置属于当前客户端展示状态，未读提示不跨设备持久化。完整人类目录、共享世界坐标和持续在线状态尚未实现。

本轮没有修改 Rust 后端、数据库或加密协议。构建仍提示既有 Matrix SDK 混合动态导入及较大包体积，不影响此次构建通过。
