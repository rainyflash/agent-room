# 游戏房间界面验收

日期：2026-09-05。本次按用户纠正的产品方向，将大厅改为 AI 人物活动的游戏房间。版本号未变更，本记录不代表安装包或线上服务已经发布。

## 交付范围

- 2.5D 等距大房间：木地板、墙面、工位、讨论桌、休息区、绿植和人物外形。
- 角色按稳定 Agent 身份生成，状态来自既有房间投影；空闲角色在避开家具的短路径上活动。视觉动作不触发业务操作或生成虚假发言。
- 点击场景人物查看角色、状态和摘要，继续进入对应私聊；身份和连接信息按需展开。
- 大厅对话、资料、寻找人物和房间菜单使用浮层或抽屉。公共草稿、画布实例和镜头在普通面板切换时保留。
- 手机保留游戏场景，支持缩放和拖动；无 WebGL 时渲染同一套房间与人物的 SVG 画面。高对比和受限设备仍可使用完整列表。
- 减少动画设置和后台页面暂停角色动画，键盘方向选择、详情关闭后的焦点恢复继续可用。

## 验证

| 检查 | 结果 |
| --- | --- |
| 项目 `check` | 格式、ESLint、国际化、类型、协议生成物与事件命名空间通过 |
| 单元测试 | 108 个文件、449 项通过 |
| 全量浏览器回归 | 42 项通过，覆盖桌面与手机 |
| Web 生产构建 | `corepack pnpm@10.28.0 build` 通过 |
| 桌面前端构建 | `corepack pnpm@10.28.0 --filter @agent-room/web build:desktop` 通过 |

新增验证覆盖人物地面落点、完整运动周期的家具避让、离线和减少动画、实际鼠标点击人物后发送私聊、关闭浮层保留画布与草稿。浏览器同时验证 200 人容量、SVG 备用画面、键盘和 WCAG 自动扫描、资料按需读取以及手机实际发送资料。

默认本地夹具展示 24 位示例角色，`?agents=200` 用于容量场景。浏览器使用测试适配器验证完整前端交互，没有用生产账号发送消息。实际 Agent 回复仍需要对应宿主运行并接收会话。

构建仍有既有 Matrix SDK 混合动态导入和大包体积提示。本次未修改 Rust 后端、加密协议或安装包发布流程。
