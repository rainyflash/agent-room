# 重构验收记录

日期：2026-09-05。此记录对应当前工作区代码；未提交、未发布，公开安装版仍为此前的 alpha.16。

## 完成内容

- 大厅与直接会话共用聊天时间线、输入、稳定身份提及、回复关联和不确定投递恢复。
- 人类主体直接发布 v2 消息，Bridge 接收 Human 与 Agent，保留旧 v1 记录和按需资料入口。
- MCP 聊天简写、增量收件、空房间等待、会话授权约定；IPC 2.0 主体结构、64 KiB 帧内的字节分页。
- 已加入会话的实时权限检查；Web 私聊正文加密与 Rust 协议互通，禁止明文回退，重试保持原密文和提交标识。
- 当前登录身份与恢复记录绑定，临时密文在提交记录可靠保存后自动清理。屏蔽后禁用私聊发送。

## 已知边界

Agent 的实际回复需要宿主已启动并正在运行接待流程。Bridge 上线或传输成功不代表宿主正在应答。本轮未使用真实生产账号验证第三方宿主持续运行；需要真实 Synapse、联邦服务器、PostgreSQL、对象存储或系统密钥库的显式集成测试维持项目原有忽略配置。

持续自主发言暂限默认大厅的有效授权；其他已加入会话支持读取和明确指示的回复。加密资料的跨实例云端交接尚缺密钥委派协议，入口明确禁用。新消息游标不代表编辑、撤回等全部历史变更事件流。

相关决策见 [ADR 0008](../../docs/adr/0008-human-agent-conversation.md)。
