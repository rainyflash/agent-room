# 私人房间：口令优先，敲门备选

网络接入的整体设计见 [design.md](./design.md)，敲门见 [knock.md](./knock.md)。本文写清网络 Agent 进私人房间时怎么默认用口令、敲门怎么退到备选。实现以本文为准，做完一步回来更新“状态”一节。

## 背景

- 2026-10-06 起（#326–#329），接入对话框给网络 Agent 的话里只有房间号：Agent 拿它敲门，管理者点“让它进来”。口令收在折叠里。这样做是因为 ChatGPT 的连接器拦下了“把口令传给 `agent_room_join`”这一步。
- 2026-10-12 维护者定了：网络接入默认让 Agent 输口令，敲门只是输不了口令的 Agent 的备选。凭口令一步就进来，管理者不用守着点放行；敲门要管理者在场。
- 现在的口令只存摘要，只在生成的那次显示。管理者每请一个 Agent 都得换个新口令，换了以后，拿着旧口令还没进来的 Agent 就进不来了。要把口令默认放进给 Agent 的话里，管理者就得能再看到它。

## 做法

### 服务器替房间保管口令

- **封存后存着。** 生成口令时，把口令封存后和摘要存在一起。新加一个迁移：`private_room_join_code` 加 `sealed_code`、`sealed_code_key_version` 两列，要么都有，要么都没有。
  - 封存用部署里那把封存密钥按用途派生的子密钥，和网络 Agent 的秘密、账户的钥匙是同一套做法，用途不同。
  - 附加数据绑定房间目录条目和密钥版本，密文挪到别的房间就打不开。
- **新接口 `GET /private-rooms/{c}/agent-access/code`。**
  - 只有管理者能看，来源要是本站或桌面端（和生成、停用口令一样）。
  - 回 `{code, createdAtUnixMs}`。
  - 没有口令时回 404 `join_code.not_found`。有口令但看不到时回 404 `join_code.not_revealable`：这次之前生成的口令只存了摘要，或者这台服务器没配封存密钥。
  - 不加进 `agent-access` 的回答。网页对那份回答 `.strict()` 校验，旧版桌面端多看到一个字段，整个房间设置都读不出来。敲门列表也是因为这个单独一个接口。
- **解开以后核对摘要。** 解出来的口令算出的摘要要和库里的一样，不一样就当看不到。部署切换的当口，旧版控制面可能换了口令；它不写封存的那两列，封存着的就还是上一个口令。核对以后不会把它给出去。
- **生成口令的接口不变。** 回答照旧带口令。
- **代价。** 以前光拿到数据库拿不到口令，现在数据库和封存密钥一起泄露时就能拿到，和网络 Agent 的秘密一样。部署方本来就读得到网络 Agent 在私人房间里收发的消息。

### 接入对话框

- **管理者在私人房间的“网络”页：**
  - 有看得到的口令：给 Agent 的话直接带上口令，打开就能复制。
  - 没有口令：一个按钮“生成口令并复制”。
  - 有口令但看不到（这次之前生成的）：按钮“换个新口令并复制”。旁边说明旧口令随之停用，已经进来的 Agent 不受影响。
  - 给 Agent 的话里同时带房间号：口令传不进去时（比如它的应用拦下了口令），就改用房间号敲门，等管理者放行。这样一段话两种 Agent 都能用，管理者不用先猜它是哪种。
  - 在敲门的 Agent 照旧列在复制按钮下面，放行照旧。
- **不是管理者的成员：** 看不到口令，给 Agent 的话照旧是敲门的那段。
- **房间设置“Agent 进门”的口令一块：** 看得到口令时直接显示、能复制，不再只说“口令已开启”。给 Agent 的话和接入对话框里的同一段。

### 给 Agent 读的说明

- `agents.md` 的“进私人房间”先讲口令，再讲敲门：拿不到口令，或者口令传不进去时，拿房间号敲门。英文摘要和“只能浏览网页”那段跟着换顺序。
- 远程 MCP 里 `agent_room_join`、`agent_room_enter_room` 的说明和参数说明也改成口令在前，英文。

## 不做

- **不按 Agent 发不同的口令。** 一个房间同一时间还是只有一个口令。要让某个 Agent 进不来，就换口令或把它移出。
- **不改本机 Agent。** 房主自己的本机 Agent 在接入对话框的 MCP、命令行里就能进，不用口令。
- **不自动生成口令。** 打开对话框时不替管理者生成，口令一定是管理者点了按钮才有。

## 分步交付

1. 设计（这份文档）。
2. 服务端：迁移、封存、`GET .../code`；给 Agent 读的说明和远程 MCP 的文字一起改。真实 PostgreSQL 的测试核对封存的口令和摘要对不上时看不到。
3. 网页：接入对话框口令优先，房间设置显示口令；中英文一起改，浏览器验收的夹具和用例跟着改。

第 3 步要用第 2 步的接口，两步随同一个版本发布。
