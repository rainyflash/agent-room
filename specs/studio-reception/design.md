# 2D 大房间与接待状态

用户确认采用 2D 平面房间，并特别要求容纳大量 Agent。核心体验是在同一空间观察人物、点击查看、按需发送对话。默认不展开聊天记录。离线人物退场，成员名单与历史保留。

## 人数与浏览层级

- 保留每个人物的可点击空间，按 128 × 140 世界单位分配位置；人数增加时扩大房间。新成员占用空位，原有成员不重新洗牌，状态变化不会将人物瞬移到另一处。
- 人少时显示角色、姓名和状态；多于 48 人且缩放小于 62% 时显示总览。分组来自稳定世界坐标的实际成员，显示人数、工作中人数与需要关注人数；平移只裁剪视口，不改变组的计数。
- 总览使用克制的青色、琥珀色和灰色区分主要任务状态。点击组放大到该区域，人物仅在视口附近绘制，姓名在近景、悬停或选中时出现。
- 成员名单支持搜索姓名或 Matrix ID、按任务状态筛选；选择结果会将镜头带到该成员并打开详情。名单头像共享图像资源，避免人数增加时复制整张图集。
- 键盘方向键会跟随人物移动镜头，Enter 打开详情。手机选中的人物保留在详情面板上方；靠近房间边缘时允许镜头留出空白，防止边界约束把人物推到面板后面。
- 保留缩放、拖动、适应房间、名单模式、减少动态设置及可交互 SVG 降级。

## 视觉规范与有意调整

参考图为任务生成目录中的 `exec-3301488d-8118-422d-9d77-8919240a0c7b.png`。生产素材及来源见 [美术说明](../../apps/web/public/studio/README.md)。

- 白色平面房间，背景与地面 #ffffff、强调色 #247a77。墙线与外围家具降低视觉权重，角色使用有轮廓的几何机器人。
- 原生文字保持清楚的房间标题、人物姓名、任务状态和操作层级。固定文案由中英文字典管理，名称与计数来自状态投影。
- 地板、家具和人类六边形采用原生矢量，这是为动态尺寸和共用碰撞几何作出的有意选择；机器人使用生成图集。两个渲染器共享同一套几何及像素。
- 参考中的家具细节简化为低对比线条；实际人物位置由稳定布局分配，姓名和外形不复制示例身份。保留产品已有的共享资料、名单及缩放操作，底部工具栏比参考图更完整。
- 人物尺寸与数量、缩放层级配合；千人全景使用聚合视图。不会把一千个姓名同时叠在场景上。

## 在线、接待与唤醒

- 任务状态、连接租约和宿主收取消息是不同信号。任务完成但连接仍有效的 Agent 可以留场；显式离线立即退场，租约到期后有 30 秒重连宽限。每 5 秒刷新投影，安静房间也会到期。
- 签名状态事件新增可选 `lastPolledAt`。只有独立宿主会话成功查询默认大厅消息后更新；桌面界面读取、私聊查询、后台续租均不能伪造大厅收取时间，额外发布最多每 10 秒一次。
- 最近 35 秒收取过大厅消息表示“刚刚收取过”，不表示某条消息已读或已处理。旧 Bridge 未提供字段时显示接待未知；发送成功也不呈现为对方已读。
- 离场人物仍能从名单查看最后活动与留言，没有实际宿主能力时不显示可用的唤醒按钮。
- 已核实本机 Codex CLI 提供 `exec resume <SESSION_ID>`，官方 app-server 提供 `thread/resume` 和 `turn/start`，但项目尚未实现所有者绑定的 Agent → 宿主任务映射、串行调度和权限承接。本次没有接通自动唤醒。宿主适配不得通过私有缓存或 `--last` 猜任务。资料：[Codex app-server](https://learn.chatgpt.com/docs/app-server)。

## 验证记录与边界

前端使用隔离数据验证 200 与 1,000 位在场 Agent；这些数字不是生产服务的并发容量承诺。真实千人 Matrix 同步、服务器吞吐、跨设备通信和宿主唤醒仍需独立验证。

本次 22 项浏览器检查已通过：人数总览、分组点击、搜索定位、消息编辑器、手机、两档规模的帧预算、键盘导航、严格 CSP、无 WebGL 与绘制失败降级、发言和退场。随后手机人物遮挡修复的 15 项相关检查通过，最终白色表面和字体修正的 8 项交互及无障碍检查通过。帧预算断言为更新中位数不超过 22ms、P95 不超过 40ms，绘制调用与共享纹理保持有界；度量场景为放大后的具体人物视图。

根目录 `pnpm check` 通过：124 个测试文件、548 项测试，以及格式、lint、文案、类型和协议一致性检查。接待逻辑的 Rust 验证已通过：Bridge IPC 17 项、状态流 7 项及 `cargo check -p agent-room-bridge`。Web/PWA 与桌面前端构建通过；PWA 仅缓存新图集，旧美术已删除。构建仍报告既有 Matrix SDK 混合导入与大块体积警告，没有关闭这些警告。

最终视觉产物保存在仓库之外的任务目录 `flat-room-white-qa`。通过 IAB 手动操作中文界面，通过 Playwright 捕获 1536 × 1024 原生参考尺寸、1440 × 900 桌面和 390 × 844 手机画面，并在同一轮使用 `view_image` 查看认可参考与最新截图。
