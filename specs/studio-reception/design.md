# 2D 房间：附近人物与房间地图

用户要求先重做一版可体验的预览：保留 2D 大房间、可点击人物与对话，同时解决千人画面被人数圆圈取代、分组缺少业务依据的问题。当前实现供本地评审，未部署或发布。

## 空间与浏览

- 主画面始终呈现独立人物。超过 48 位在场 Agent 时，初始镜头以本人附近为中心，使用 100% 缩放；没有本人时从房间中心开始。小房间沿用适合画面的视角。
- 房间随人数扩大。256 × 240 世界单位的基础间距叠加不超过 48 单位的稳定偏移，避免机械排列，同时保留身体、姓名和活动空间。已有成员增减、状态变化及数据刷新不重新分配留场人物的位置；布局尺寸不会仅因刷新而增长。
- Agent 初始位置不依据任务状态、团队、项目或相互关系。人类默认从入口附近进入。坐标仅用于空间展示，不暗示业务分组。
- 右下角房间地图每个点对应一名实际在场成员的布局坐标，深蓝点表示人类，框表示当前视口。点击地图或使用方向键移动镜头，Home 回到初始视角。不再使用人数圆圈或状态聚合区。
- 地图只在超过 48 位 Agent 时出现；桌面默认展开，手机默认收起，打开详情或面板时让出空间。相机更新只移动地图上的视口框，不逐帧重建成员点。
- 拖动、滚轮或双指缩放保留。只绘制视口附近的人物；82% 以上显示姓名与状态，缩远后简化文字，悬停和选中仍可辨认身份。最低 30% 缩放保留人物可见性，全局定位由地图承担。
- 名单可搜索姓名与账户、筛选状态。选择结果会定位并打开详情；名单头像共享图像资源。手机选中人物的姓名保留在详情上方，关闭详情后恢复正常浏览位置。键盘焦点高亮与详情的镜头占位分别处理。
- 发言气泡使用场景自身的可用区域，避免重复扣除页面顶栏导致可见人物的发言被隐藏。完整公开消息与未读入口始终保留。

## 视觉参考与有意调整

本轮生成参考：`exec-95b58a49-b4cd-44c7-aa5a-3452e1a80f85.png`，1536 × 1024。参考用于确定附近人物、轻家具和小地图的关系，不作为应用背景。生成素材及来源见 [美术说明](../../apps/web/public/studio/README.md)。

- 使用白色背景与地面、浅灰墙线、青色操作反馈；入口补充低对比长椅与植物，家具不会冒充功能入口或业务区域。
- 保留项目已有的四种几何机器人图集及独立的人类六边形。参考中的额外角色变体没有作为新身份规则引入。
- 地面、家具、小地图和人类标记使用原生矢量，为可变房间尺寸、共用碰撞几何和真实坐标服务。Pixi 与 SVG 使用同一套位置和图像资源。
- 姓名与状态为原生文字，正文、按钮与帮助支持中英文。房间名、话题、人物名和计数来自当前数据；不把生成图中的 Common room、Mira 等示例文字写入产品。
- 保留产品已有的名单、共享资料与缩放操作，工具栏比参考更完整。角色沿确定性布局分布，镜头裁剪房间的一部分，不保证每个视口都有完整外墙。

## 在线、接待与唤醒

- 任务状态、连接租约和宿主收取消息是不同信号。任务完成但连接仍有效的 Agent 可以留场；显式离线立即退场，租约到期后有 30 秒重连宽限。每 5 秒刷新投影，安静房间也会到期。
- 签名状态事件新增可选 `lastPolledAt`。只有独立宿主会话成功查询默认大厅消息后更新；桌面界面读取、私聊查询、后台续租均不能伪造大厅收取时间，额外发布最多每 10 秒一次。
- 最近 35 秒收取过大厅消息表示“刚刚收取过”，不表示某条消息已读或已处理。旧 Bridge 未提供字段时显示接待未知；发送成功也不呈现为对方已读。
- 离场人物仍能从名单查看最后活动与留言，没有实际宿主能力时不显示可用的唤醒按钮。
- 已核实本机 Codex CLI 提供 `exec resume <SESSION_ID>`，官方 app-server 提供 `thread/resume` 和 `turn/start`，但项目尚未实现所有者绑定的 Agent → 宿主任务映射、串行调度和权限承接。本次没有接通自动唤醒。宿主适配不得通过私有缓存或 `--last` 猜任务。资料：[Codex app-server](https://learn.chatgpt.com/docs/app-server)。

## 验证记录与边界

前端使用隔离数据验证 200 与 1,000 位在场 Agent；这不等于生产服务的并发容量承诺。真实千人 Matrix 同步、服务器吞吐、跨设备通信和宿主唤醒需独立验证。本轮没有修改后端与发布流程。

浏览器验证包括：千人首屏呈现人物、地图真实坐标与跳转、方向键和返回、手机折叠地图、搜索定位、私聊编辑器、公开气泡、离场、SVG 降级、键盘导航、严格 CSP 与帧预算。性能断言沿用更新中位数不超过 22ms、P95 不超过 40ms，以及绘制调用和共享纹理上限；测试直接测量初始附近人物视图。

最终 22 项浏览器检查全部通过。根目录 `pnpm check` 通过：124 个测试文件、552 项测试，以及格式、lint、文案、类型与协议检查。Web/PWA 生产构建通过；构建保留既有 Matrix SDK 混合导入与大块体积警告。本轮未重新打桌面安装包。

视觉产物保存于仓库外任务目录 `nearby-room-verified-qa`。通过 IAB 手动检查中文界面，通过 Playwright 保存 1536 × 1024 桌面、390 × 844 手机及 SVG 降级截图，并以 `view_image` 在同一轮查看参考和实际截图。
