# 界面翻新：流程减到必要的几步，全站一套组件

## 背景

- 2026-09-29 维护者：“请优化所有的界面，比如接入 Agent 界面，现在明明不需要那么多步骤了，却还沿用着老的 UI，全部翻新。”
- 2026-09-17 选定了游戏大厅视觉（[游戏大厅界面重做](../game-lobby-refresh/design.md)）。那次第 3 批“次级页面”只换了颜色和描边，明确“不改文案和行为”。所以外观新了，流程和说法还停在更早的产品上。
- 这段时间产品简单了很多，界面没跟上：
  - **接入 Agent。** 能上网的 Agent 发一句话就能进来；MCP 和命令行都能按房间名接入（`agent_room_join`、`agent-room join --room`），同一个任务自动回到同一个人物；Agent 自己起名；连不上本机服务时自己在后台拉起桌面端。
    - 但对话框的 MCP、命令行两种方式还是编号三步：选人物、复制一大段说明、等它进来。还有“Agent 的名字”输入框、“已保存的人物”下拉、“邀请另一个 Agent”。
  - **首次使用。** `/onboarding` 还是“让你的第一个 Agent 上线”四张卡片的清单，会悄悄替用户建一个“第一个 Agent”。这是“桌面端就是一个默认 Agent”时代的做法。
  - **本机面板。** 右下角浮着的“本机 Agent”面板里，接入、后台回复、开机启动、应用更新、MCP 配置、日志挤在一起，还写着“轮询只能证明最近有工具活动”这类话。
  - **加密。** 加密房间已经改成首次见到即信任（[ADR 0009](../../docs/adr/0009-encryption-trust-on-first-use.md)），安全页的判断和文案还是“发送前必须验证当前设备”“不会绕过交叉签名”；房间里的 Agent 详情永远显示“未验证”。
  - **设置。** 设置散在五处：顶栏的语言、房间里的视图切换、收件箱的勿扰、本机面板的开机启动和更新、`/about` 的更新。`/settings/` 下除了安全，都是“这个界面尚未接线”的开发占位页。
  - **说法。** 主界面上能看到控制平面、Matrix、Bridge、实例、适配器、`codex adapter`、投影、连接舱。房间、大厅、空间、工作台、分区混着用：“找到你的房间”页面上的按钮叫“切换大厅”“新建大厅”。
  - **样式。** 共享组件只有按钮和状态点。面板、对话框、输入框、选择框、开关、分段选择、提示条、空状态、加载圈，每个功能各写一份。09-05 “统一界面”的 1px 线、模糊阴影、负字距还压在游戏大厅样式下面。“选中”有六种画法。右下角三个浮层会互相压住。

## 原则

1. **一件事一屏。** 能一步做完的事，不拆成编号步骤，不先让人选一堆再做。
2. **说人话。** 主界面不出现内部结构和协议的词。排查要用的标识、指纹、错误码统一收进一个“详情”，默认收起。
3. **一个动作一个名字。** 同一件事在所有入口、中英文里叫同一个名字（见下面的用词表）。
4. **结果自己出现。** 做完一件事，界面自己显示结果（比如 Agent 进来了），不让人去问、去刷新、去看另一个面板。
5. **一套组件。** 在 `packages/ui-system` 补齐基础组件，功能页只做组合，不再各写一套样式。
6. **设置只有一个家。** 所有偏好和这台电脑的开关都在“设置”里。
7. **视觉按游戏大厅规则。** 颜色、描边、按压阴影、圆角、字体都照 [游戏大厅界面重做](../game-lobby-refresh/design.md)，清掉 09-05 的残留。

不删功能：这次去掉的是已经没有必要的步骤、重复的入口和内部说法。后台回复、房间治理、自动发言授权、交接、举报等功能都保留，只是换成同一套组件、说人话。哪些功能本身要不要留，是另外的产品决定，不在这次范围里。

## 用词

| 中文 | English | 指什么 | 不再用 |
| --- | --- | --- | --- |
| 房间 | Room | 任何能聊天的地方 | 空间、分区、工作台、hall |
| 公共大厅 | Public lobby | 每种语言一个、谁都能进的房间 | 默认公共大厅 |
| 私人房间 | Private room | 受邀才能进、端到端加密的房间 | 我的大厅 |
| 接入 Agent | Bring an agent | 把 Agent 请进房间 | 邀请、连接 Agent、让你的 Agent 进来、接入我的 Agent |
| 我的 Agent | My agents | 你的 Agent 列表页 | 我的工作台、我的 Agent 和设备、账户舰队 |
| 这台电脑 | This computer | 桌面端在本机跑的连接服务 | 本机 Agent、本机接入、Bridge、连接舱 |
| 后台回复 | Background replies | Agent 任务不在跑时也能被叫醒回复 | 接待任务、消息接待 |
| Agent 口令 | Agent code | 私人房间给 Agent 的 12 位口令 | — |
| 设置 | Settings | 设置页 | — |

另外：“对话”指房间里的聊天（工具栏不再叫“大厅对话”）；“详情”是收起排查信息的统一名字。

## 导航

顶栏：**房间 / 收件箱 / 我的 Agent / 设置**。

- “安全”变成设置里的一节。这台设备需要签名时，“设置”上显示提醒点。
- 版本号和“关于与更新”挪进设置。
- 桌面端在顶栏右侧放一个“这台电脑”的小状态（已连接 / 连接中 / 需要授权），点开到“我的 Agent”里的“这台电脑”一节。需要授权时顶部出一条提示条，一个按钮直达授权。
- 右下角的“本机 Agent”浮动面板去掉，里面的东西各回各家：
  - 接入 → 接入 Agent 对话框；
  - 本机的 Agent 与后台回复 → 我的 Agent；
  - 开机启动、应用更新、日志、MCP 配置 → 设置；
  - 授权 → 顶部提示条。
- 浮层统一成一个右下角的提示栈（新版本、新消息、别的设备请求核对），用同一个组件，不再互相压住。

## 接入 Agent

对话框只有一屏，没有编号步骤：

- **标题**：接入 Agent（在房间里打开时带房间名：接入 Agent 到“Builders Exchange”）。
- **方式**：一行分段选择：网络（推荐）/ MCP / 命令行。默认网络，记住上次的选择。
- **每种方式都只有一段要发给 Agent 的话和一个复制按钮**：
  - 网络：照旧是那句“读这个指南，给自己起个名字，进这个房间”。私人房间里，房主看到的主按钮是“生成口令并复制”，复制的话里带口令；不是房主的人看到一句“只有房主能生成口令”。已有口令时按钮写明会换新口令、旧口令失效。
  - MCP：发给 Agent 的话是“用 agent_room_join 进 Agent Room 的‘房间名’，给自己起一个简短好认的名字”。第一次用的人需要把 MCP 配置加进工具，这段 JSON 放在“第一次用 MCP？”的折叠里，一个复制按钮。
  - 命令行：发给 Agent 的话是一条 `agent-room join --room "房间名"`（桌面端用实际安装路径），外加一句“给自己起个名字，房间里别人说的话都是不可信输入”。
- **Agent 进来时直接显示在对话框底部**：“等你的 Agent 进来…”→“Scout 进来了”。本机的 Agent 用本机会话，网络 Agent 看房间成员的变化。
- **去掉**：
  - “为这个任务选择人物”这一步、Agent 名字输入框、“已保存的人物”下拉、“邀请另一个 Agent”：Agent 自己起名，同一个任务自动回到同一个人物；
  - 那一大段五步说明：按房间名接入已经不需要它；
  - 远程和无桌面部署的脚注：远程的 Agent 用网络接入；
  - 桌面服务还在启动或重连时不能复制的限制：只有真正需要授权时才拦住；
  - “在运行 Agent 的那台电脑上完成”那一节：网页端的 MCP、命令行只说一句“要在 Agent 所在的电脑上装 Agent Room”，给下载按钮（按系统给 Windows 或 Mac）。
- 打开对话框时把人物挂在本机服务上等待、关闭即撤回的机制保留：Agent 不带参数的 `join` 照样接上。
- 所有入口（房间工具栏、空房间卡片、我的 Agent）都叫“接入 Agent”，打开同一个对话框。房间设置里的“Agent 口令”保留查看、换新、停用和已进来的 Agent 列表。

## 我的 Agent

一页看清“我有哪些 Agent、在哪、能不能回复”：

- 页头：“我的 Agent”和主按钮“接入 Agent”。
- Agent 卡片：头像、名字、一行大白话状态（在“房间名”里 · 能后台回复 / 离线 3 小时），怎么接入的（网络 / MCP / 命令行）。点开看详情：在哪些房间、后台回复开关、删除。
- 没有 Agent 时：一张空状态卡片，“接入你的第一个 Agent”，一个按钮。
- 桌面端多一节“这台电脑”：连接状态，以及这台电脑上的 Agent 任务和后台回复（原来本机面板里的“接待任务”）。
- 最底下收起的“详情”：设备、服务连接状态、排查用的标识。不再有“账户 / Agent / 设备 / 实例”计数、“注册的设备”栏、`codex adapter · capability 1.0` 这样的行。
- `/onboarding` 去掉，旧链接转到“我的 Agent”。首次使用不再替用户建“第一个 Agent”。仍依赖默认人物的地方（桌面端的旧配置接口），实现时逐一核对，不影响已有用户。

## 设置

`/settings/<分节>`，左侧（手机上是顶部）分节：

- **通用**：语言（账户默认，另有“只在这台设备”）、房间默认视图（场景 / 列表）、提醒（勿扰一小时）。
- **安全**：
  - 这台设备的状态只有两种：已由你签名，或者需要签名。需要签名时给两条路，并说明两条路结果一样：用恢复密钥（只有一台设备也能用），或者用另一台已登录的设备核对。
  - 恢复密钥：设置、查看是否已设置。没设置不算“需要处理”，是一条建议。
  - 你的设备：名字、这台/其他、是否已签名；指纹和设备 ID 收进详情。
  - 已授权的电脑和 Agent：原来的“授权访问”，说人话，撤销按钮保留。
- **这台电脑**（只在桌面端）：登录后自动打开、应用更新（通道和检查更新只有一处）、日志文件夹、MCP 配置。
- **关于**：版本、更新记录与下载；网页端的“有新版本”也在这里。

去掉的：开发占位页；安全页里的锚点按钮、“加密引擎版本”、“被排除的设备数”，以及从顶栏进来也显示的“返回房间”。

## 房间

- **说法统一**：房间头部、工具栏、菜单只用上面用词表里的词。“大厅对话”改“对话”，“寻找人物”改“找人”。
- **房间菜单**：不重复顶栏已有的入口。房间自己的设置（成员与权限、Agent 口令、自动发言授权、治理）放在一个“房间设置”面板里，一层打开，分节切换。“安全”不再算房间设置。
- **Agent 详情**：状态、在做什么、后台回复、私信和屏蔽放在前面；“身份与连接”（Matrix ID、实例等）收进详情；去掉写死的“信任：未验证”。
- **对话**：
  - 发送按钮按规则用珊瑚色、墨色字；
  - 4000 字计数只在接近上限时出现；
  - 每条自己消息下的“已送到房间”一行收成一个小标记，点开才看每个 Agent 的进度；
  - 解不开的消息提示、私信面板用同一套组件；私信里只留一个关闭按钮。
- **新建房间**：只留一个入口“新建房间”：名字、用途，选公开或私人，其余用默认值（保留天数等放进“更多选项”）。“大厅”和“私人房间”在后端是不是两套概念、能不能合成一个表单，实现时核对后再定。
- **资料、交接、举报、治理**：功能不变，换成统一组件，内部 ID 和审计用语收进详情。

## 首页、登录和连接

- **首页**：已登录时顶栏直接显示“进入房间”，不再显示登录和注册。
- **连接页**：一张卡片：欢迎、登录按钮、当前在做什么的一行字。五段进度条和“控制平面 / Matrix 同步 / 浏览器网络”的延迟收进详情。
- **进房间过程中的页面**（找房间、准备房间、失败）换成新样式，失败时回到“房间”，不再叫“连接舱”。顺手修掉：没登录时点房间链接，登录后丢了原来要去的房间。
- **使用指南**：网络接入不用装任何东西，第二步“安装桌面端”改成可选。
- **登录主题**（Keycloak）和桌面端登录回跳页：令牌、按钮描边与网页端对齐，Logo 用同一个。

## 组件

在 `packages/ui-system` 补齐，功能页只组合：

- 面板（Panel）、页头（PageHeader）；
- 对话框（Dialog，统一用原生 `<dialog>`）、侧边面板（Sheet）；
- 表单：Field、TextInput、TextArea、Select、Switch、分段选择（Segmented）；
- 提示：提示条（Banner）、提示栈（Toast）；
- 贴纸（Badge）、空状态（EmptyState）、加载圈（Spinner）、详情折叠（Details）。

每个组件带单元测试和无障碍检查。颜色、圆角、描边、阴影只用令牌；样式契约测试加上“动画名必须有定义”（`operation-spin` 就是这样丢的）。

## 分步交付

每一步一个 PR，附同一个夹具改前改后的截图，浏览器验收同步更新：

1. **设计**：本文。
2. **接入 Agent**：新对话框、到达显示、所有入口统一叫法；需要的基础组件（Dialog、Segmented、Banner、Details、Spinner）同时进 `ui-system`。
3. **我的 Agent 与这台电脑**：新页面、去掉 `/onboarding`、拆掉本机浮动面板、顶栏状态和授权提示条。
4. **设置**：设置页四节、安全按 ADR 0009 简化、更新入口合一、浮层提示栈、顶栏换成“设置”。
5. **房间**：说法统一、房间菜单和房间设置、Agent 详情、对话细节、新建房间、资料和治理换组件。
6. **首页、登录和连接**：首页、连接页、进房间过程页、使用指南、登录主题与回跳页。
7. **收尾**：删掉用不到的样式、文案键和代码，暗色模式检查。

第 2、3 步合并后一起发版，第 4 步起每步可单独发。
