## B. 账号级云端工作区

- [x] 3. 建立 Agent Directory 云端端口与 Adapter
  - 为 `GET /agents` 增加严格 Zod 契约和类型安全客户端。
  - 复用设备与实例端口，不让 UI 直接拼 HTTP。
  - 增加成功、未认证、损坏响应和网络失败测试。
  - _需求：1、3、8_

- [x] 4. 建立 Fleet 领域投影
  - 按稳定 `agentId` 聚合 Agent、实例和设备。
  - 计算当前设备、实例在线状态、最后在线时间和异常孤儿数据。
  - 为多设备、零实例、撤销实例和重复数据增加测试。
  - _需求：3、4、7_

- [x] 5. 实现账号工作区页面
  - 新增 `/workspace`，登录后默认进入该路由。
  - 展示 Agent、实例、设备、宿主类型、最后在线和所有权信息。
  - 提供加载、空状态、失败、重试和键盘操作。
  - _需求：1、3、9_

- [x] 6. 拆分云端与本机状态
  - 引入 Control Plane、Matrix、Bridge、Agent 四层状态模型。
  - 顶层状态条和诊断面板分别展示，不再使用单一“已就绪”。
  - _需求：4、9_

## C. 运行时能力组合

- [x] 7. 把互斥 RuntimeMode 重构为能力组合
  - 云端服务成为所有交互式客户端的共同核心。
  - `localRuntime` 改为可选端口，删除缺字段联合服务模型。
  - 单一 Router 承载 Web 与桌面云端页面。
  - _需求：1、2_

- [x] 8. 把桌面 Runtime 改为增强层
  - 根布局在 Tauri 可用时挂载 Runtime Provider 和“此设备”抽屉。
  - Bridge 离线只影响本机操作，不再重定向整个应用。
  - 保留宿主检测、MCP 配置、授权、更新和日志入口。
  - _需求：2、4、9_

- [x] 9. 实现桌面人类云端登录协议
  - 增加 PKCE 与短期授权事务。
  - 实现系统浏览器登录、`agent-room://` 回调和一次性 code 交换。
  - 把用户会话与 Bridge Agent 凭据彻底隔离。
  - 增加重放、state 不匹配、过期和撤销测试。
  - _需求：2、7、8_

- [x] 10. 删除桌面平行产品路径
  - 删除独立 Desktop Router 和 Bridge-only 大厅路由。
  - 将有价值的本机诊断组件迁入 Runtime 抽屉。
  - _需求：2、4_
