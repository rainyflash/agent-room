# 修改密码，顺带退出别的地方的登录，设计

状态见文末“状态”一节。

## 背景

2026-11-07 查注册失败时，维护者问要不要做找回密码、修改密码、邮箱验证码登录。查下来：

- **找回密码**已经有：登录页的“忘记密码？”发一封重设密码的信。
- **修改密码**没有：应用里没有入口，身份服务自带的账户页面也没给人用。想换密码只能退出登录、走“忘记密码”。
- **邮箱验证码登录**不做：等于把账户交给邮箱，验证信还常被邮箱扫描器先点掉（见 CLAUDE.md“生产问题自动汇总”）。

维护者定了做修改密码，顺带退出别的地方的登录：换密码多半是怕密码泄露了，光换密码，别人已经登录着的照样能用。

## 维护者定的（2026-11-07）

1. 设置的“账户”里加“修改密码”。
2. 改好以后，这个账户在别的浏览器和电脑上的登录都退出。

## “别的地方的登录”有哪几样

一个人登录着，手上有三样，各管各的：

| 哪一样                     | 存在哪                                            | 改密码以后                                      |
| -------------------------- | ------------------------------------------------- | ----------------------------------------------- |
| 身份服务的登录             | Keycloak 的会话（浏览器里的 Cookie）              | 别的都结束（改密码的页面上强制勾上）            |
| 账户登录                   | 控制面的 `web_session`（网页的、桌面端的）        | 别的都撤销，正在用的这一份留着                  |
| 聊天登录                   | Synapse 上这个人的设备（网页的、桌面端的）        | 别的都注销，正在用的这一台留着                  |
| 这台电脑的授权             | Bridge 的设备授权                                 | **不动**                                        |
| Agent 连接                 | Agent 的 Matrix 账户和设备                        | **不动**                                        |

账户登录不靠身份服务的登录续命（`specs/session-lifetime/design.md`），只结束身份服务那边的话，别处的网页和桌面端照样能用，所以三样都要动。

电脑授权和 Agent 连接不是凭密码拿到的，撤了以后 Agent 全要重新接入、电脑要重新授权，代价大；要撤去设置的“安全”里撤（11-07 起不用重新登录、能一次撤几台）。改好以后的提示里说清楚这一点。

## 怎么改

### 流程

1. 设置 →“账户”→“修改密码”。网页走 `/auth/oidc/start?intent=change-password&returnTo=/settings/account`，桌面端由原生层开系统浏览器走 `/auth/desktop/start?intent=change-password`。
2. 身份服务先看最近登录过没有（和别的登录一样带 `max_age`，5 分钟）：没有就先输一次现在的密码。然后是“修改密码”页：新密码输两遍，保存或取消。
3. 回到控制面的回调。改好了：撤销这个人别的账户登录，回到设置时地址上带 `passwordChanged=1`（桌面端在回环地址上带）。取消了：照常登录回来，什么都不撤。
4. 设置页看到 `passwordChanged=1`，调 `POST /auth/sign-out-elsewhere`，带上这台的聊天设备号；服务器注销别的聊天设备、结束身份服务上的登录，回退出了几处。页面说“密码改好了，别的地方的登录都退出了”，没退成的给“再试一次”。

### 控制面（第 2 步）

- `/auth/oidc/start`、`/auth/desktop/start` 认 `intent=change-password`。授权地址多带 `kc_action=UPDATE_PASSWORD`（Keycloak 的“应用发起的动作”），别的和登录一样。桌面端这一种和 `reauthenticate` 一样，不拿浏览器里已有的网页登录换。
- 回调认 Keycloak 带回来的 `kc_action`、`kc_action_status`（以前 `deny_unknown_fields` 会把它们当成坏请求）。
  - `kc_action=UPDATE_PASSWORD` 时，认证时间的上限放宽到“最近登录的 5 分钟”再加“一次登录最长的 10 分钟”：发起时身份服务按 5 分钟把过关，人在改密码的页面上可能停了几分钟，这时认证时间已经超过 5 分钟，不放宽的话密码改好了、回来却说“这次登录没有完成”。一次登录本来就只能等 10 分钟，再久的回调照旧不认。
  - `kc_action_status=success`：登录照常建好以后，撤销这个人别的账户登录。网页留着刚建的这一份；桌面端的这一份要等桌面端拿授权码去换，所以全撤。撤的时候库出了错不挡登录（密码已经改好了），页面接着调的接口会再撤一遍，出错在那边报。
  - 回到网页时在回跳地址上加 `passwordChanged=1`；回到桌面端时在回环地址上加同一个参数，原生层再把它加到回跳地址上。
  - 这两个参数是身份服务经浏览器带回来的，谁都能自己加上。加上的人只能撤掉自己别的登录，没有别的用处。
- 新接口 `POST /auth/sign-out-elsewhere`，正文 `{"keepChatDeviceId": "…"}`（可以不带）：
  - 同源检查，只要有效登录（不要最近登录过，理由见“代价”），网页的、桌面端的登录都认。
  - 撤销这个人别的账户登录（正在用的这一份留着）。
  - 以应用服务的身份冒充本人，列出 Synapse 上这个人的设备，除了 `keepChatDeviceId` 那台全部注销（`POST /delete_devices?user_id=…`；应用服务调它不要交互认证，Synapse 1.159 的 `DeleteDevicesRestServlet` 写着）。只动这个人自己的设备，Agent 是别的 Matrix 用户，碰不到。
  - 结束这个账户在身份服务上的全部登录（和退出登录同一个 `SignInSessionTermination`）。这个浏览器的也一起结束，这里的账户登录不受影响，只是下次要最近登录过时得输密码。结束不成只记告警。
  - 回 `{"accountSessions": 撤了几份, "chatDevices": 注销了几台}`。Synapse 不通时回 503 `sign_out_elsewhere.chat_unavailable`，账户登录已经撤了，再调一次是安全的。
- 新加的端口：`WebSessionStore::revoke_others`（一条 `UPDATE`，回撤了几份和登录服务上的账户），`MatrixHumanDeviceSignOut`（列设备、注销设备）。不加表、不加列。

### 身份服务主题（第 2 步）

`login-update-password.ftl` 在“应用发起的动作”里（`isAppInitiatedAction`）：

- 标题“修改密码”，引导语“设一个新密码。保存以后，这个账户在别的浏览器和电脑上的登录都会退出。”
- 不显示“同时退出其他设备上的登录”的勾选框，改成隐藏的 `logout-sessions=on`：Keycloak 默认不勾，不勾的话别的浏览器在身份服务上的登录还在，悄悄就能再登录回来（2026-11-07 在本机 Keycloak 26.7.2 上试过：不勾时另一个浏览器 `prompt=none` 照样登录成功；勾上以后回 `login_required`）。

忘记密码那一路（邮件里的链接）不变，勾选框照旧给人自己选。

### 网页和桌面端（第 3 步）

- 设置的“账户”加一节“密码”：一句说明和“修改密码”按钮。网页直接跳去登录起点；桌面端经原生层开系统浏览器（`DesktopAuthenticationIntent` 加 `ChangePassword`），回来照旧走 `desktop://human-session-changed`。
- 回到 `/settings/account?passwordChanged=1`：先把参数从地址栏去掉、在这个标签页的 `sessionStorage` 里记一笔（刷新不会再退一遍；等聊天时页面跳走又回来也还记得），再调 `POST /auth/sign-out-elsewhere`，带上这台的聊天设备号。退成了才删那一笔。
  - 聊天还在连（启动、恢复、同步、去聊天登录、重连、断网）就先等，连上了带着设备号去退，免得把这一台的聊天登录也注销了；连不上（出错）就不带，连这一台的一起退，下次打开要重新聊天登录。
  - 进行中：“密码改好了，正在退出别的地方的登录……”
  - 成了：“密码改好了。别的浏览器和电脑上的登录都退出了。这台电脑的授权和 Agent 连接没动，要撤去‘安全’里撤。”
  - 没成：“密码改好了，但别的地方的登录还没全部退出。”说新密码已经能用了，加“再试一次”，错误码跟在说明后面。
- 桌面端原生层：回环回调多认一个 `passwordChanged=1`，交给网页的回跳地址带上它；回环服务器本来就只看有没有 `code` 和 `state`，多一个参数照收。

## 代价

- **新接口只要有效登录。**“退出别的地方”是保护自己的动作，和 11-07 定的“撤销电脑不用重新登录”一样：拿到登录的人能用它把你别处的登录全退掉、自己那份留着，是添麻烦，拿不到别的。要是要求最近登录过，人在改密码的页面上停久了，回来就退不成，又得登录一次。
- **从网页改密码，同一台电脑上的桌面端也会退出**，它也是“别的地方”。桌面端退出账户登录以后 Agent 照常（电脑授权不动），重新在应用里登录就好。
- **这个浏览器在身份服务上的登录也结束了**，下次要最近登录过的操作要输新密码。

## 兼容

- 旧版网页和桌面端没有“修改密码”的按钮，不会带 `intent=change-password`。
- 新接口是新加的，网页按 `.strict()` 校验的那些回答都没动。
- 第 2 步先上：服务器认了、网页还没按钮，什么都不变。第 3 步的网页碰上还没更新的服务器（回滚时），`intent=change-password` 回 400，按钮报错、详情带错误码。

## 验收

- 第 2 步：
  - 应用层：`change-password` 的授权带 `UpdatePassword` 这种交互；回调 `success` 撤了别的、留着新的；`cancelled` 不撤；认证时间超过 5 分钟、不到 15 分钟时改密码的回调照收，普通登录照旧拒。
  - 控制面路由：起点认 `intent=change-password`；回调认 `kc_action`、`kc_action_status`，回跳地址和回环地址带 `passwordChanged=1`；新接口的同源检查、没登录 401、Synapse 不通 503。
  - PostgreSQL：`revoke_others` 只撤这个人没撤销的、留着指定那份（真实库的测试，派发 `suite=all` 跑）。
  - matrix-provisioning-adapter：列设备、留一台、注销其余，冒充的是本人（模拟 Synapse 的测试）；不认 Agent 的用户。
  - 本机 Keycloak 26.7.2 上用主题走一遍：改密码页没有勾选框、另一个浏览器的身份服务登录结束。
- 第 3 步：组件测试覆盖按钮、回来以后去掉参数只调一次、成了和没成的提示、再试一次；浏览器验收用 `my-agents.html?settings=account&passwordChanged=1`（加 `&signOut=failed` 是第一次没退成）。

## 状态

- 2026-11-07 维护者定了做修改密码、顺带退出别的地方，起草这份设计。
- 2026-11-07 第 1、2 步（#752）：控制面认 `change-password`，回调撤别的账户登录、带 `passwordChanged=1`，新接口 `POST /auth/sign-out-elsewhere`；改密码页强制退出别处。和设计不一样的一处：改密码页的保存按钮写“保存密码”，和忘记密码那一页一样，不用 Keycloak 的“提交”。在本机 Keycloak 26.7.2 上用这一版主题走过一遍：中英文标题和说明对、只有隐藏的 `logout-sessions=on`、改好回来带 `kc_action_status=success`、另一个浏览器 `prompt=none` 回 `login_required`；不是从应用来的“设置密码”页照旧有勾选框。
- 2026-11-07 第 3 步：设置“账户”里加“密码”一行，网页和桌面端都走 `change-password`；桌面端原生层认 `DesktopAuthenticationIntent::ChangePassword`，回环回调多认一个 `passwordChanged=1`（只认 `1`、只认一次），交给网页的回跳地址带上它（放在 `#` 前面，带上以后太长就照原样）。和设计不一样的几处：
  - 回来以后在标签页的 `sessionStorage` 里记一笔“还要退出别的地方”，退成了才删：等聊天连上的时候页面可能跳去聊天登录，回来还要接着退。
  - 聊天还在连时先等，连不上才不带设备号（设计里写的是“还没连上就不带”，那样刚打开页面、还在恢复聊天时就会把这一台也注销）。
  - 没退成的提示不单说聊天登录：账户登录、身份服务的登录也可能没退成，改成“还没全部退出”，并说新密码已经能用了。
  - 桌面端等人在系统浏览器里改密码时，按钮下说一句去刚打开的浏览器页面里改。
