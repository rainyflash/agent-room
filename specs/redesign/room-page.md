# 房间页重排：对话占主栏、Agent 表格（第 1 块）

[重新设计总纲](./design.md)的第 1 块。只动网页（桌面端里也是这份网页），不动控制面、Bridge 和协议。设计稿是 Artifact“房间页重排与子房间”的第 1、2、3、7、8 张。

## 背景

现在的房间页是“场景在下、对话浮在上面”（`features/lobby/ui/lobby-page.tsx` 的 `ReadyLobby`）：

- 整页是场景，别的东西都是绝对定位压在上面，没有栏的概念（`lobby-game.css`）。
- 对话是右边一块浮着的面板（`.room-panel`，宽 `clamp(440px, 36vw, 600px)`），要点底部工具栏的“对话”、点一个人或者点气泡才出来。地址里不带 `view` 就是场景。
- 面板里从上到下是：标签（对话 / 资料）、公告、“房间里的所有人”一行、消息、输入框。1440×900 的屏上消息只占整个屏幕的一成多。
- Agent 名单有三个地方：场景里的人物、底部“找人”打开的抽屉、右下角切到“列表”以后的名册（`list-mode-roster.tsx`）。名册一个 Agent 占三行，没有列。
- 场景还是列表记在账户偏好里（`lobbyView`，随聊天账户同步，只认 `scene`、`list` 两个值），默认场景，手机上也是。
- 底部工具栏放着对话、共享资料、找人、接入 Agent、邀请人、分享；房间名、房间设置和“几位 Agent 在场”在顶上那一条（`room-beacon.tsx`）。应用的顶栏不在这一页上。
- 对话里能查找（按关键词、人、日期、话题），没有“只看提到我的”；正文认代码块、行内代码、粗体、标题、列表、引用，不认表格，链接只显示成文字。
- 每个 Agent 的状态已经分得很细：在等消息、下次运行时读、重连中、离线（离线了多久），谁的、是不是网络 Agent 也查得到。后台回复开没开，只知道你自己的 Agent 的。

## 想要的样子

打开房间就是对话。电脑上从左到右：

1. **左边一栏**（有东西才出现）：主房间、子房间（第 2 块）、私聊。
2. **中间主栏**：最上面一行收着的房间须知，然后是对话和输入框。
3. **右边一栏**：Agent 表格和房间里的人。

顶上一条是房间名和几个动作：对话 / 场景切换、分享、邀请人、接入 Agent、房间设置。底部工具栏没有了。

场景没有删：切到“场景”就是现在这一页，原样留着。

## 规则

### 视图：对话和场景

- 顶栏右边一个两段的切换：“对话”（新的默认）和“场景”（现在的房间页）。
- 选了哪个记在这台设备上（`localStorage`），不进账户偏好：账户偏好里的 `lobbyView` 只认两个值，旧版客户端读到第三个值会出错。`lobbyView` 和“设置 → 通用 → 房间视图”照旧管场景视图里面是画面还是名册。
- 地址里多一个 `layout=scene`：带着它就是场景视图，这时 `view` 的意思和现在一模一样（不带是场景，`conversation`、`resources` 是打开面板）。不带 `layout` 时看这台设备记着的，没记过就是对话。
- 对话视图里 `view` 不带或者是 `conversation` 都是对话，`resources` 是资料。以前发出去的带 `?view=conversation` 的链接照样对。
- 一定要名册的设备（高对比度、内存很小的）在场景视图里照旧自动用名册，对话视图不受影响。

### 布局

- 宽度 1100px 以上三栏：左栏 216px 上下，右栏 320 到 380px，其余给主栏。主栏里一行字最宽 720px。
- 768 到 1100px 两栏：右栏收成顶栏上的“Agent 5”按钮，点开是从右边出来的一栏；左栏收进房间名旁边的下拉。
- 768px 以下一栏，见下面“手机宽度”。
- 左栏只在有东西的时候出现：这间房里你有私聊，或者（第 2 块以后）有子房间。只有主房间一项时不占地方。
- 每一栏自己滚动，整页不滚。输入框一直贴在主栏底下。

### 顶栏

- 左边：回到房间列表、房间名、一行小字（公开还是私人、几个人、几个 Agent）。归档、只能看的状态也写在这行。
- 右边依次：对话 / 场景、分享（公开又能分享的房间才有）、邀请人（你能邀请时才有）、接入 Agent（归档了没有）、房间设置（有人申请加入时带一个点）。
- “接入 Agent”是这一页唯一的主按钮。
- 底部工具栏去掉以后：“对话”不用了（一直在）；“共享资料”是主栏上“对话 | 资料”里的一项；“找人”不用了（右栏一直在，带搜索）。

### Agent 表格

- 右栏两个标签：“Agent”（带个数）和“人”（带个数）。
- “Agent”下面一行小字汇总：几个在等消息、几个叫得醒、几个离线。然后是搜索框和表格。
- 列：**名字**（小机器人头像、名字带编号）、**谁的**（你、某人的昵称、“网络”）、**状态**。
- 状态照现在的五种说法，只是写短：在等、下次运行时读、重连中、离线的写离线了多久（“3 天前”）、不知道的留空。每行最前面一盏灯（见下面“风格”），灯之外都带字，不靠颜色分。
- **叫得醒**：没在等消息，但开着后台回复，@ 它会回。第 1 块只给你自己的 Agent 标（你自己的后台回复登记本来就读得到）；别人的 Agent 现在没有地方能读，要服务器新给，放在第 4 块。
- 排序照现在名册的分组：在等的在前，然后下次运行时读、重连中，离线的按离线的先后。不再画分组标题，离线的整行变灰。
- 点一行：右栏换成这个 Agent 的详情（就是现在的 `AgentInspector`，@ 它、私聊、屏蔽、后台回复都在里面），上面有“回到列表”。地址里照旧是 `?agent=`。
- “展开成整页”：表格占满主栏和右栏，多出几列：怎么来的（这台电脑、别的电脑、网络）、进来的时间、你给它的标签和收藏，还有按状态、标签筛选和翻页。数据都是现在名册已有的。
- “人”标签：昵称、身份（房主、管理员）、他带了几个 Agent。
- 没有 Agent 时，右栏是一句话加“接入 Agent”按钮，主栏的对话照常能用。

### 对话

- **筛选**：对话上面一行三个：全部、人说的、提到我的（带没读的条数）。“提到我的”是点了你的名字、@所有人、或者回复你的话。查找照旧在右边。
- **Agent 之间的长串折起来**：连着 4 句以上都是 Agent 说的、谁也没点人或回复人的话，折成一行“甲和乙之间又说了 6 句 · 展开”。
  - 最下面还在进行的那一串不折。
  - 里面有点了你的、回复你的，不折。
  - 展开只管这一次打开；对话的“详情”里能整个关掉这个折叠，关没关记在这台设备上。
- **表格**：正文认管道线写的表格，放在自己能左右滚的框里。
- **链接**：`https://`、`http://` 开头的链接能点，点了先弹确认，写出完整地址和域名，确认才在新标签页（桌面端是系统浏览器）打开。别的写法、图片、HTML 照旧只显示成文字。
- **回复的是哪句**照旧显示在消息上面，点一下跳到那句。
- 长消息的折叠、已送达的小标记、解不开的提示、“回到最新”都不变。
- 须知（现在的公告）收成主栏最上面一行，点开看全文；有没看过的改动时带一个点。拆成须知和置顶是第 4 块。

### 手机宽度

- 一栏，就是对话。顶上一条：回到房间列表、房间名（点开是主房间、子房间、私聊的下拉）、“Agent 5”、一个“更多”。
- “Agent 5”点开是从下面出来的一整页表格，只有名字和状态两列，“谁的”写在名字下面一行。
- “更多”里是分享、邀请人、接入 Agent、房间设置、场景。
- 筛选三项留着，查找收进“更多”。

### 风格：门牌与灯

2026-11-13 的第一稿只是把现在的样子收了收（粗边变细、阴影去掉、圆角变小），维护者看过说：还可以更有特色、更优雅。第二稿不再是“收一收”，而是给界面定一个自己的说法：

**每间房有一块门牌；有 Agent 在里面等着回话，这间房的灯就亮着。** 界面别的地方退到纸和墨后面去，琥珀色只留给灯。机器人照旧是每个 Agent 的头像，也留在空状态、官网、围观页和场景里。

设计稿第 3 张是这一套的说明，第 1、2 张是白天和夜间的房间页。

看得见的三样东西：

- **灯**：代替现在表示在线的绿色。一直带着字，不只靠灯分。
  - 亮着（实心，外面一圈光）：在等消息。
  - 一圈：叫得醒。
  - 灰的实心点：连着，没在等（下次运行时读、重连中）。
  - 灰的空心圈：离线。
  - Agent 表格每行最前面一盏；左栏每一间后面也有一盏，里面有 Agent 在等就亮；顶栏房间名下面写“几个在等消息”，前面也是它。夜间的配色里灯带光晕。
- **门牌**：你现在在的那一间，在左栏里是一块 1.5px 墨线框起来的牌子，名字用衬线字。设置里选中的那一节、一组单选里选中的那一项，也是这个样子。
- **门**：子房间名字前面的小图。门框是没有门，关着的门是要批准，实心的门带锁眼是只能请进来（见[子房间](./sub-rooms.md)）。一条细线把它们串成一条走廊。

三条规矩：

1. 琥珀色只给灯，别的地方不用黄。主按钮从黄色改成墨色。
2. 珊瑚色只表示轮到你了：发送、提到你的、新消息那条线。
3. 一页只有一条墨线（顶栏下面那条）、一个墨色的按钮（房间页上是“接入 Agent”）。别的线都是细线。

对话里：

- 人的头像是一枚墨色的方印（一个字），Agent 是机器人头像，一眼分得出是人说的还是 Agent 说的。
- 折起来的那一行、日期、仓库动态是衬线小字，夹在两条细线中间，像剧本里的舞台说明。
- 提到你的那一条整行铺一层浅珊瑚色，左边一条珊瑚色的线。

令牌（`packages/ui-system/src/styles.css`，夜间是现在 `prefers-color-scheme: dark` 那一套）：

| `--ar-surface`（面） | `#fffdf7` | `#fffefb` | `#1a1922` |

做的时候要留意的：

- 灯和门是两个新的小组件，放进 `packages/ui-system`；灯的四种样子各有一句读屏的话。
- 写死的要一处处收：往下的实心阴影约 22 处、2px 以上的边 8 处、写死的圆角约 130 处。
- 字体：去掉 Fredoka 和站酷快乐体，加 Fraunces 和思源宋体。思源宋体按字块分片、用到才下，可桌面端安装包要带上全部分片。动手前先量安装包大了多少：超过 8 MB 就只给拉丁字母用衬线，中文标题改用思源黑体的粗体。换字体要改 `pnpm-lock.yaml`，同一个 PR 提交许可证清单。
- 登录页的主题和官网的颜色跟网页端有测试卡着一致（`tools/tests/test_brand_consistency.py`、官网生成器的测试），要一起改。改登录主题的那一版发版要设备码。
- 官网首页那间房的画（机器人、家具）不重画；底色换了以后看一眼协不协调。
- 场景（Pixi）里面的配色不动；场景视图外面那一圈（顶栏、面板、工具栏）跟着令牌变，画面是可爱的、外面一圈是素的，这个不协调先接受，默认已经不是它了。
- 对比度：正文和次要的字在两套配色里都过 4.5:1；灯、门这些图形过 3:1。

## 做法

### 网页

- `ReadyLobby` 拆成两个：现在这份整个留给场景视图（`layout=scene`）；新写一个对话视图，用栏布局（CSS grid），不再绝对定位。
- 对话视图直接用现成的：`MessageLayer`、`ConversationPanel`、`ConversationComposer`、`ConversationSearch`、`RoomNoticeBar`、`InviteReplyProgress`、`DirectConversationDock`、`DirectSessionNavigation`、`AgentInspector` 的内容，各个对话框（房间设置、邀请、分享、接入 Agent）。
- 表格新写（现在的名册是一排按钮，不是表格），数据和排序用现成的 `LobbyAgent`、`agent-attendance.ts`、`filterLobbyAgents`、谁的和是不是网络 Agent 的查询。“展开成整页”用现在名册的筛选和翻页。
- 路由：`shared/routing/route-state.ts` 的 `LobbySearch` 多一个 `layout`；`lobbySearchWithRoomPanel`、`lobbySearchWithView` 只在场景视图里照旧用。
- 未读：`RoomActivityStore` 现在只在对话面板关着时数未读。对话视图里对话一直看得到，按“窗口在不在前台、是不是滚在最底下”算。
- 折叠和筛选是纯函数，放在 `features/conversation/domain`，输入是已经投影好的消息，带单元测试。
- 表格和链接改 `domain/chat-markdown.ts`：多两种节点。链接只认 `http`、`https`，确认框用 `ui-system` 的对话框；桌面端经现成的“在系统浏览器里打开”。
- 不登录的围观页（`public-watch-view.tsx`）抄了房间页的类名和样式，这一块不动它，它照旧用场景那一套样式；所以 `lobby-game.css`、`lobby-workspace.css` 里场景视图用到的不能删。
- 文案中英文一起加，说法照[界面翻新](../interface-renewal/design.md)的用词表，新加三个词：

| 中文 | English | 指什么 |
| --- | --- | --- |
| 主房间 | Main room | 一间房自己的对话（有子房间时用来区分） |
| 叫得醒 | Wakes on mention | 没在等消息，但开着后台回复，@ 它会回 |
| 房间须知 | Room brief | 挂在对话上面的常驻说明（现在叫公告） |

### 测试

- `apps/web/e2e` 里 22 个用例打开 `lobby-scene.html`。大约 10 个断言默认看到场景、3 个点“场景 / 列表”：这些在地址里加上 `layout=scene`，别的不改。
- 大约 12 个点底部工具栏的（邀请、接入 Agent、分享、对话、资料）：改成在对话视图里点顶栏，因为那才是人默认用的；场景视图里各留一条冒烟。
- 共用的 `openRoomSettings`、`openDirectConversation`、`expectCompleteRosterPages` 跟着改。
- 夹具 `lobby-scene.html` 不带 `layout` 时跟应用一样默认对话视图。
- 无头验收（`e2e-vertical`、`e2e-live`）里走房间页的也要过一遍，在 PR 分支上派发 `suite=all`。
- 新加浏览器验收：三种宽度下三栏、两栏、一栏；筛选；折叠和展开；表格排序和点一行；链接确认；键盘能走完顶栏、表格和输入框。

## 不做

- 不删场景，不动 Pixi 那一套。
- 不改账户偏好的格式。
- 不动围观页的布局（第 3 块做分享页实况时一起看）。
- 不做“上次说话”这一列：没有可靠的数据，只有已经加载的消息。
- 不让链接直接打开，不显示图片。
- 应用的顶栏（房间、发现、收件箱、我的 Agent、设置）照旧不出现在房间页里，回去靠左上角的箭头。

## 安全

- 链接：只认 `http`、`https`；确认框里写完整地址，域名单独写一行，带非 ASCII 字符的域名同时写出转码后的样子；打开时不带来源（`noopener noreferrer`）。Agent 那边照旧不因为一条消息就打开链接（接入说明里的那一条不变）。
- 表格里的格子按文字处理，不解析 HTML。
- 折叠只是显示，不改消息、不影响已读位置。

## 维护者定的

- 2026-11-13：默认是对话加 Agent 表格，场景降成可选的视图、不删；风格收一收、不扔（见总纲）。
- 2026-11-13 看过第一稿：总体设计得不错；整体视觉风格还可以更有特色、更优雅。照这句话出了第二稿“门牌与灯”，等他看。

## 分步交付

每步一个 PR，前一步合了再做下一步。

1. **1a 对话视图**：栏布局、顶栏、须知一行、右栏先放现成的紧凑名册；地址 `layout`、这台设备记着的选择；默认还是场景，从顶栏切过去。带新的浏览器验收。新写的样式只用令牌，不写死颜色、圆角和阴影。
2. **1b 换默认**：默认改成对话视图；用例照“测试”一节改；派发 `suite=all`。
3. **1c 风格**：改令牌和字体、加灯和门牌、收写死的样式、同步登录主题和官网。维护者看过第二稿点头再做。
