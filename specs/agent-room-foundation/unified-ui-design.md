# 全界面统一设计

## 目标与范围

以已确认的平面 2D 房间为产品中心，统一官网、连接流程、房间目录、我的 Agent、接入引导、安全中心、房间内对话与资料面板、桌面运行设置和授权返回页。保留真实身份、在线状态、消息、权限、恢复及更新流程；本次不发布版本。

| 项目 | 规范 |

| 状态 | 可用、等待、失败均有文字与图标，颜色只作辅助 |

## 页面与组件清单

- 官网：完整的左右双栏首屏、可用的入口和下载、三个旅程说明；房间插图完整放入容器。
- 连接：左侧欢迎与进度，右侧当前阶段、操作与可展开诊断；窄屏优先操作。
- 房间目录：等权重的横向条目，安静的环境缩略图、真实计数、明确入口；搜索及空/失败状态沿用。
- 我的 Agent：设备、人物列表、详情三栏；分隔线代替层叠卡片；窄屏人物优先。
- 接入和安全：统一标题、步骤、字段、列表、危险操作及对话框；接入配置和密钥保持可读可复制。
- 房间：保留 2D 场景、相机、小地图和千人容量逻辑；统一导航、检查器、对话、资料、成员面板及工具栏。
- 桌面：沿用共享前端；本地运行、更新和自动启动面板采用同样控件；原生授权返回页匹配色彩与排版。

## 概念与实现边界

先生成六张完整页面参考，再提取上述规范。参考图覆盖官网、目录、Agent 管理、连接、安全、房间面板。这些是本次实施的设计参考，不能替代真实业务状态，也不表示用户逐张确认过参考图中的每个细节。

原生文本、控件及场景几何仍由代码绘制。复用现有生成的平面机器人素材。官网及欢迎页中的无名称人物明确为装饰插图，不进入业务数据；房间目录不伪造参与者。概念图自动添加的身份、日期、导航、状态或不存在的操作不会进入产品；实际文案、数据与功能优先。
