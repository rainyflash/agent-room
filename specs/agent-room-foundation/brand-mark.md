# Agent Room 品牌图标

图标以打开的房间轮廓和两个伙伴为形象。青色底与界面主色一致，白色轮廓在小尺寸下保持清晰，两个圆点表示进入同一空间的人与 Agent。右下入口留白，不添加文字、连线或细小装饰。

## 唯一源文件

`apps/web/public/agent-room-mark.svg` 是可编辑的矢量源文件，采用 64 × 64 画布。根节点的 `color` 属性定义品牌主色；圆角方形使用该颜色，主体使用白色与浅薄荷色。核心图形位于图标中央的安全区域内，供系统圆形、圆角方形等蒙版裁切。

修改后从仓库根目录运行：

```powershell
corepack pnpm@10.28.0 brand:sync
```

脚本调用项目锁定版本的 Tauri CLI，将同一个源图同步为：

- 网页页眉与 SVG favicon、180px Apple touch icon、192px / 512px PWA 图标。
- 桌面应用 PNG、Windows ICO、macOS ICNS 及仓库已有的各平台尺寸。
- 桌面授权返回页的内联 SVG。
- Codex 插件标识与插件品牌颜色。

网页 PNG 图标随 PWA 静态资源预缓存。生成文件不单独手工修改。更新源码与生成资产不等于发布或替换已安装的桌面应用。

## 验证

检查 16px、24px、32px、48px 与 128px 显示，以及浅色和深色背景。浏览器实际页眉、favicon 和授权返回页应加载同一标记。生成过程中的系统字体扫描提示不影响图标；源图不含字体依赖。

本次已完成上述视觉检查，网页构建、ESLint、Prettier、Rust 格式及两项桌面回调测试通过。额外验证了三份 SVG 内容一致、PWA PNG 实际尺寸与清单相符且进入离线缓存、Windows ICO 包含 16 / 24 / 32 / 48 / 64 / 256px 图层。没有打包发布安装程序或更新已安装插件。
