## 1. 架构边界

- `domain::content` 只表达长度、媒体类型、摘要、加密模式、扫描状态和单向生命周期，不依赖 Axum、SQLx、AWS SDK、Matrix SDK 或 ClamAV 协议。
- `application::content` 把上传、完成、事件绑定、票据签发、正文打开和回收拆为独立用例；每个用例只依赖窄端口。统一 `ContentService` 只是 Facade，不承载隐藏业务规则。
- `postgres-adapter` 保存幂等声明、访问策略、生命周期与下载窗口账本；`content-adapter` 独立实现 S3、ClamAV、随机对象键和 HMAC 票据；`matrix-adapter` 只提供当前房间成员与 Power Level 事实。
- `control-plane` 是唯一组合根：装配具体适配器、认证 HTTP 边界和可关闭后台回收任务。领域层没有反向依赖基础设施实现。

## 2. 上传与私有对象

- 客户端先提交 UUIDv7 幂等键、房间、访问模式、SHA-256、长度、媒体类型和加密模式。相同键与相同声明返回同一 Content ID；篡改任一声明字段返回冲突。
- 建立声明前先查询当前房间成员关系，拒绝后不会生成对象键或写数据库。Content ID 与对象键均不可猜测，对象键不含显示名、Room ID 或原文件名，也不会出现在 HTTP 响应。
- 正文以有界临时文件完成摘要与长度校验，再使用 S3 `If-None-Match: *` 条件写入。重复完成不会重写对象，同键不同元数据不会覆盖既有内容。
- 服务端可见明文通过 ClamAV `INSTREAM` 分块协议扫描。客户端 E2EE 密文只校验大小和摘要，扫描状态为 `not_applicable`，服务端不尝试解密。
- 摘要不一致、扫描拒绝或持久化失败保留阶段化错误，并尝试把元数据转为 `orphaned` 后删除对象；补偿错误不会覆盖原始失败。

## 3. 授权、票据与读取完整性

- PostgreSQL 只解析活跃主体到 Matrix User ID；最终授权始终读取 Matrix 当前成员与 Power Level，不使用最终一致成员投影。
- `room_member`、`sender_only` 和 `room_admin` 三种策略先要求当前仍在房间；管理员采用 Matrix 标准默认 50 门槛，并正确处理自定义与无限 Power Level。
- 读取票据由 HMAC-SHA256 签名，绑定票据版本、Key ID、主体、Content ID、内容版本和到期时间，最大寿命硬限制为五分钟。路径与票据内容不一致时不会查询仓储。
- 票据签发后若成员被移除或权限下降，真正打开正文时再次查询 Matrix 并拒绝。过期票据在触碰数据库与对象存储前失败。
- 对象元数据摘要/长度不一致时不返回任何正文；流式正文在结束前重新计算 SHA-256 与长度，存储正文被篡改会以显式完整性错误终止。
- PostgreSQL 下载窗口以主体为键原子累计请求数与字节数，多个控制平面副本共享同一预算；达到边界后返回精确重试时间。

## 4. 生命周期与运行时

- 生命周期闭合为 `uploading → active → orphaned/redacted/expired → deleted`，禁止删除后复活或绕过扫描直接激活。
- Matrix 事件发送成功后执行幂等绑定；重复绑定同一 Event ID 成功，换绑到另一事件冲突。已激活但长期未绑定事件的对象按“事件提交失败”处理并回收。
- 回收任务查询卡死上传、未绑定活跃对象、孤儿、撤回和过期对象。单项对象删除失败只记录该项，不阻塞同批其他对象；成功删除后保留最小审计元数据。
- 后台 worker 延迟一个周期后首次执行，任何时刻最多一个批次运行；进程关闭时停止调度并等待在途批次结束。
- 启动配置严格校验 S3、ClamAV、票据、Matrix 授权身份、下载预算和回收周期。缺少密钥、公开明文端点、非 UUIDv7 身份或越界预算均直接拒绝启动，调试输出不泄漏秘密。

## 5. HTTP 与安全边界

- 浏览器请求只接受安全会话 Cookie 与精确同源；设备请求继续使用短期 Token 和 Ed25519 原始请求证明。上传正文证明签署摘要与长度声明，不把大正文缓存为字符串。
- JSON 路由保持小型默认 Body Limit，正文上传单独关闭 Axum 默认上限后由领域声明和流式存储执行实际大小限制。
- 所有错误映射为稳定代码、类别、HTTP 状态和关联 ID；响应统一 `no-store`。依赖错误日志只记录阶段与闭合故障类型，不记录正文、对象键、票据或凭据。
- 正文读取由控制平面流式代理并附带标准 `Digest`、精确长度、媒体类型和私有缓存策略；对象桶保持私有，不暴露永久 URL。

## 8. 明确边界

- 内容授权服务 Matrix 身份必须保持在所有受管房间内。当前读取适配器在检查者不在房间时失败关闭，因为离房客户端看到的是 state-at-leave，不能作为当前授权真相。任务 18/房间运行时接线必须复用该服务身份创建房间或显式邀请并确认加入。
- 客户端 E2EE 内容无法做服务端病毒扫描，这是加密边界，不是待修 Bug。客户端解密后的本地扫描与交付确认属于任务 27、28。
- 当前下载配额按主体限制请求数和字节数；房间、Agent 与 IP 的复合容量治理属于公开测试前任务 37、39。
- HMAC 编解码器支持旧验证密钥，但首版运行配置只装配一个活动密钥。生产轮换必须在任务 37 的 Secret 管理中加入旧密钥窗口，或等待最长五分钟票据自然失效后切换。
- 本任务交付内容 API 与服务端生命周期。Matrix 预览事件、未知提交对账、编辑/撤回关系和客户端按需打开流程属于任务 18–21，不用假事件或假 UI 冒充完成。
