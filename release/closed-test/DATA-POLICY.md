# 封闭测试数据策略

- Matrix 保存房间成员、权限、事件历史、设备和端到端加密密文；控制平面保存账户、设备、Agent、目录、治理、内容引用和审计事实。
- 公共消息默认保留 30 天。私人房间和直接会话遵循房间策略；上下文交付包短期存在且只能消费一次。
- 远端正文只有在用户显式打开后才下载；只有再次明确确认后，选定内容才交给本地 Agent。
- 不收集模型隐藏推理、原始系统提示、密钥或完整工具日志。结构化日志、指标和错误必须通过敏感输出扫描。
- 测试数据必须使用生成身份和假凭据；封闭测试运营者负责在测试结束后清理数据库、对象和本地 Bridge 状态。
- 账户导出与删除工作流已经实现。删除会移除本服务可控的账户、设备、Agent、内容引用和对象；已发送到独立联邦服务的事件及依法保留的最小审计记录不能保证同步物理删除，界面和导出结果必须明确说明该残留。
