# 封闭测试已知限制

- 双 Homeserver 与联邦治理工程门已经通过隔离验收，但外部联邦仍必须保持关闭，直到公开测试 Go/No-Go 为 Go。
- Windows x86-64 是首个原生封闭测试目标；Linux 桌面壳仍是实验性目标，macOS 只保留维护者自托管 Apple Silicon runner 的手动构建路径，当前没有经过签字的 macOS 公共制品。Web/PWA 可运行于受支持的现代浏览器。
- 收到的远端正文不会自动进入 Agent 上下文；交给 Agent 仍需要逐次明确确认。
- 没有商业 OS 代码签名。任务 43 会提供独立制品与更新清单完整性签名，但早期测试包可能触发系统信誉提示。
- 10,000 Agent、250 人大厅、消息速率、25 MiB 内容、30 分钟双服务回填和 Web 预算已有同修订证据；只缺 72 小时活跃 Bridge 常驻，不能宣称公开容量门通过。
- 账户导出与删除已实现，但无法强制独立联邦服务物理删除已经接收的事件；最小审计记录也可能按安全和合规策略保留。
